# 月光黏土視覺統一

本輪由家長授權 Codex 直接決定視覺細節，並追加特效一致性要求。

- 分支：`art/polish`；工作目錄：既有 `erin-art-polish`，重跑沿用。
- 基於已合併 D6 的主線；保留既有黏土角色。
- 範圍：render 外觀、CSS、截圖工具、畫面測試基準與機械版本同步。
- 不改玩法、碰撞、數值、存檔、Maker 或權限。
- 開始、升級、設定與試煉選單統一深紫面板／冰藍主按鈕。
- 低對比地磚、細邊刻線，降低原本測試方格感。
- 友方斬擊／旋風／閃電／護盾／爆炸採同一冰藍線光。
- Boss 直線／扇形／落點／火環採橘色線光；弱點採粉色。
- 共用線光保留原路徑與透明度，沒有逐幀 blur、filter 或新漸層。

## 驗證

三尺寸實際 Chrome 開始 → 選武器 → 移動／自動攻擊 → 自然升級。
`node games/survivor/tools/shots.cjs --card polish-final --effects`
產生三尺寸各開場、戰鬥、升級與特效對照共 12 張；對照是固定美術展示，不能當 Boss 通關證據。
完整測試：`node games/survivor/tools/test.cjs --layout`，exit 0，123 行 PASS（含真 Chrome 多尺寸版面／操作）。git diff --check 通過。
只更新 Canvas 外觀基準，歷史戰鬥基準維持不變。

## 自評與剩餘事項

1. 舊面板與新 HUD 風格不同：本輪已統一表面、框線與按鈕主次。
2. 線條技能與霓虹子彈不一致：改為共用線光，弱點保留粉色身份。
3. 密集命中外光過白：已降低命中光暈；極密集畫面仍需手機實玩感受。

原有像素技能圖示仍保留，尚未重畫整套圖示。
尚未做 iPad 實機效能驗收，不宣稱手機 60fps 或完整商業化完成。
Godot §11：本輪只改 Web renderer／CSS；光線色彩與地磚可作移植參考，未驗 Godot。
正式站尚未更新；家長看圖／試玩後決定發布。

## 本機效能紀錄與 FOLLOWUPS

隔離 Chrome headless 固定 200 個怪物繪圖實體＋旋風區域，150 幀採樣去除前 21 幀。
只量暫停場景 renderer：平均 1.83ms，p95 2.30ms；rAF 間隔 p95 17.80ms。
這不是 200 怪完整遊戲模擬／手機實機結果，不宣稱達到全遊戲 p95 ≤17ms。
FOLLOWUPS：iPad 實機與完整密集戰鬥效能、技能圖示整套換皮、Maker 展示缺口仍需保留獨立辨識色。
原工作目錄未提交的美術 runbook 完整保留。
