## 目標與顯示時機

正常生存模式在死亡或最後一關通關時，沿用既有勝敗面板、標題、圖示、配色及重玩按鈕，補上本局摘要。第一關勝利仍直接進第二關，不插入摘要。手動 Boss 試煉、Maker 編輯／試玩與 preview 模式不顯示生存摘要。

摘要只使用本局暫存資料，不增存檔鍵、跨局統計或 Maker 欄位，也不改傷害、獎勵、勝負、掉率和關卡規則。

## 顯示欄位與口徑

1. **本局時間**：沿用遊戲累計秒數，跨關累計，顯示 `Math.floor` 秒；不把暫停時間加進牆鐘時間。
2. **到達關卡與等級**：顯示終局當下關卡名稱／序號和玩家等級。死亡時表示到達，不暗示通關；最後一關勝利沿用現有勝利標題。
3. **小怪擊倒**：沿用 `state.schoolCombat.kills` 的累計口徑，含精英／大熊、不含關卡 Boss；標籤要說清楚，不使用中立道具的 `neutral.kills`。
4. **最後配裝／卡片**：列出終局仍持有的武器、秘技／大招與已取得升級卡，沿用既有名稱及等級。只列最後狀態，不加取得時間軸、消耗歷史或未取得選項；空類別顯示友善文字，不出現 `undefined`。
5. **新最長紀錄**：以更新前的最佳秒數為基準；只有本局整秒嚴格較長才顯示。平手或較短不顯示。沿用現有紀錄鍵、儲存與失敗容錯，不新增 key；先記錄舊值再比較。

## 生命週期與驗收

摘要為終局快照，只結算一次。第一關換關保留累計時間、擊倒和配裝；重新開始清空本局摘要與累計，但保留舊最佳紀錄。連續重開不能殘留前一局內容或重複加總。長配裝清單可捲動，重玩按鈕保持可操作。

需先真實 Chrome 端對端操作，再跑自動化：

- 零擊倒死亡、第一關勝利後第二關死亡、最後一關全破。
- 新紀錄／未破／平手／首次無紀錄；儲存失敗仍可結算與重玩。
- 暫停／選卡後終局，時間仍用原遊戲計時口徑。
- 多種配裝、長卡清單、空能力類別；名稱與等級正確，無 `NaN`／`undefined`。
- 重複終局事件不重複結算；至少連續重新開始兩局，第二局沒有第一局摘要。
- 手動試煉、Maker、preview 原流程及舊紀錄保持原狀。
- 1024×461、740×360、1180×820：摘要可讀、長清單可捲、重玩可操作，無遮擋。
- Mac Studio `node games/survivor/tools/test.cjs --layout` 全 PASS、版本同步與 `git diff --check` 通過。公開預覽由 Dot 實際測，不能以本機工程測試冒充雲端驗收。
