還是被切啊 畫面是橫版喔

（Grok 轉述：家長在 Android 手機實機（v23／game.js?v=20261025s）上測試，系統是直向鎖定、人橫拿，所以遊戲走的是「直拿旋轉」路徑，CSS 視窗約 412×915（螢幕截圖 461×1024）。接續最新的 main。請建立卡片 coord/tasks/survivor-levelup-layout-fix-2.json（todo）。）

截圖一（升級選卡）：三張卡各自撐滿幾乎整個可見高度，看不到效果展示，也找不到 ✓ 按鈕；只有面板左緣中間一顆小的圓形「<」。
截圖二（Maker）：技能樹分頁只看到編輯表單；右邊（旋轉後的下方）頁尾只剩擠在邊上的「挑一項開始設計吧！」，看不到卡片清單或技能樹。

Grok 用無頭 Chrome 在線上版重現（412×915、412×860、384×832 直拿旋轉，以及 915×412 橫向，結果相同）：

根本原因：
1. fitVisibleViewport() 在短邊小於 440 時設定 data-short="true"，而所有手機橫向的短邊都是 360～430，所以手機上一律觸發「小畫面備案」：#upgradePreview 和技能樹細節 display:none，卡片圖示也隱藏。也就是說手機上永遠看不到效果展示。PR #25 的測試把 vh<440 時「隱藏展示」當成通過條件，所以沒抓到。
2. .upgrade-workspace 是 minmax(0,1fr) 的那一列，三張卡 align-items: stretch，被拉到整個高度（每張約 253×284），空間都給了卡片。
3. ✓ 確認鈕只有 52px，用文字字元「✓」畫，旋轉 90 度後看起來像「<」（像返回鍵），而且壓在卡片下方中間，所以家長以為沒有確認鈕。
4. Maker 的 .maker-room 是單欄四列（toolbar／tabs／editor／footer），編輯區只有約 240px 高；沒有卡片樹或清單的區塊，頁尾只放狀態文字。

修正規格：
1. 刪掉以 440 為門檻隱藏展示的做法。改成依實際可用的面板尺寸排版：橫向（含直拿旋轉）時用兩欄，左欄是三張精簡卡片（不撐滿高度，align-items: start，卡高大約可見高度的 45%），右欄是效果展示（16:9，依剩餘空間縮放）加一行說明。真的放不下（例如可見高度小於 260）時才隱藏展示。
2. ✓ 確認鈕改用像素圖示（不是文字字元），至少 64px，固定在面板右下角，旁邊加文字「選這張」，旋轉後也不會被看成箭頭；沒選卡時顯示停用狀態。
3. 保留雙點卡片直接選、鍵盤 1／2／3。
4. Maker 在橫向時改成兩欄：左邊是卡片樹／清單（點卡片編輯），右邊是編輯面板；頁尾只放試玩按鈕和狀態，不能被擠壓。
5. 測試：在 412×915（直拿旋轉）、384×832、915×412、800×360、732×310 這些尺寸，用真實 Chrome 無頭排版、模擬觸控和 DPR 3，檢查：效果展示有顯示而且完整在可見範圍內、✓ 按鈕完整可點且至少 64px、三張卡完整可見、Maker 卡片清單和編輯面板都看得到。不可以把「隱藏展示」當成手機尺寸的通過條件。
6. sw.js 快取版號要升級。改動盡量小，快速上線。
