## 統一拼圖（效果積木）計畫 — 家長已同意「好 都改成同一套」
目標：把四種格式（engine/effect-blocks.js 規則、卡片積木、敵人 phaseAttack、武器連段／蓄力欄位）統一成主角與敵人共用的一套積木。
每個招式＝五種積木疊起來：
1. 觸發：按下、放開、蓄力完成、第 N 下、命中、衝刺、計時、碰觸、敵人 AI 就緒、波次時間。
2. 形狀：扇形、直線、圓、留缺口的圈、投射物、痕跡。蓄力只放大朝前方的形狀，不做 360°。
3. 時機：前搖（起手）→ 生效 → 後搖（收招）→ 冷卻，主角與敵人共用同一條時間軸。
4. 效果：傷害、擊退／吸引、緩速、暈眩、連鎖、召喚、補血、護盾、生怪。
5. 回饋：預警樣式、刀光、頓幀／震動強度、音效與提示。
數值可用 {ref:'schoolRules.x'} 參照共用數值。
Maker 分頁：武器、技能卡、怪物、老師、關卡、規則；每個項目旁有預覽與「試玩」，練習場不再是分頁。手機版：左邊項目圖示列、中間積木堆（每塊可收合）、右邊即時預覽（小螢幕可收成開關）；分頁圖示放上方。
## 8 步遷移（一次一張卡，前一張 merge 後才開下一張）
1. survivor-settings-menu：玩家「設定」畫面（首頁與暫停選單進入）：操作（攻擊模式、搖桿）、手感（打擊回饋強度、震動開關）、聲音（音樂／音效音量）、顯示（低特效）。獨立儲存並轉移舊存檔；Maker 只留「預設設定」小面板。
2. survivor-maker-shell：新 6 分頁外殼（列表／編輯／預覽），舊面板原樣搬家，規則頁補齊中文標籤；不改遊戲行為。
3. survivor-timing-block：共用時機積木＋時間軸元件，敵人 phaseAttack 與主角攻擊都用；主角前後搖（後搖可被衝刺取消），先只在手動模式生效。
4. survivor-weapon-blocks：武器的連段、蓄力、特殊、衝刺斬改成積木堆，舊欄位載入時自動轉換。
5. survivor-enemy-attack-blocks：敵人 phaseAttack 與舊「怪物的攻擊」改用同一套積木。
6. survivor-card-blocks-<流派>：卡片 feature 組合一次一個流派搬進 effect-blocks 規則（靜電、王冠為範例），每張補舊新等效測試。
7. survivor-feedback-block：回饋積木（預警、刀光、頓幀）＋工具：慢動作、判定框顯示、前後殘影對照、生怪工具。
8. survivor-wave-blocks：波次／關卡改為積木（時間觸發＋生怪效果）。
每張：舊存檔要能載入、升版本號、Codex 只跑 node games/survivor/tools/test.cjs（不加 --layout）、審查者在 1024×461、740×360 實際操作。
