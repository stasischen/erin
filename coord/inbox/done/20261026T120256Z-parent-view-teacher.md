## 1. 視野（每台裝置看到一樣大的世界）
- 現況：engine/loop.js 的 resize() 讓 1 個世界單位＝1 CSS 像素，沒有縮放，所以平板（1180×820）看到的面積約是手機（740×360）的 3.6 倍。
- 改成「固定面積」縮放：zoom = sqrt(cssW × cssH ÷ (800 × 400))，每台裝置看到約 800×400 的世界面積。
- zoom 取 0.25 或 0.5 的倍數，讓像素圖保持清晰，多出的部分留邊。
- state.width／state.height 改成世界單位（cssW÷zoom、cssH÷zoom），繪圖用 ctx.setTransform(ratio×zoom, …)。
- 手指／滑鼠座標換成世界座標時要除以 zoom（手動瞄準、練習場）；HUD 維持螢幕像素。
- 生怪、鏡頭外判定、鏡頭都跟著新的 state.width／height。
- 地圖大小與老師安全圈改用世界單位，不再依螢幕大小決定。

## 2. 老師戰
- 速度依階段 70／90／110（主角 190）；主角距離超過約 1 個螢幕時，以 2 倍速度快走追上，並顯示流汗提示。
- 老師在畫面外也不放棄：繼續追，並排一個拉近距離的招式；畫面邊緣顯示箭頭，加上一般預警。
- 血量依玩家已升級次數成長，目標戰鬥時間 45～60 秒。
- 第 2 階段起，國字／粉筆速度 200／240；黑板擦衝撞距離 450。
- 安全圈改用世界單位且更小（最後約為短邊 0.45 倍的半徑）；圈外每秒扣 4 血。
- 第 3 階段休息 0.6 秒（預警最短不低於 0.6 秒）。
- 新招式，全部有預警、用統一積木做：
  - 跳上講台：在主角當下位置顯示紅色落點圈（半徑約 90），起手 1.0 秒、空中弧線、落地傷害＋擊退；收招 0.8 秒並轉星星，可反擊。
  - 粉筆狙擊：遠距離時，細紅瞄準線跟著主角 0.8 秒後鎖定，射出一發快速粉筆（速度約 420）。
  - 黑板封路：主角兩側出現有預警的短牆，約 3 秒，封住逃跑路線但留缺口。
  - 黑板擦連衝（第 2 階段起）：連續 2～3 次衝撞，每次重新瞄準，預警線 0.5 秒。
  - 點名追蹤（第 3 階段）：點名圈跟著主角 1 秒，鎖定 0.5 秒後命中。
- 依距離選招：近（約 200 內）用範圍招；中距離用扇形與牆；遠或在畫面外一定用拉近距離的招式或粉筆狙擊。
- 所有數值都能在 Maker「老師」分頁調整。
