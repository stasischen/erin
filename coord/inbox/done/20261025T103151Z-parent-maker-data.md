1. 資料驅動重構：
- 把所有卡片和技能樹定義（流派、欄位、入門／進階A／進階B／終極、合體前置條件、等級、數值）、所有敵人種類（血量、速度、大小、行為、攻擊）、所有魔王招式（預警、彈幕型態、階段）從 game.js 程式碼搬到純資料，例如 games/survivor/data/*.json 或 JS 物件。遊戲引擎完全依照這些資料執行。
- 效果由一小組積木組合：projectile、aoe、chain、dash-trail、slow、stun、knockback、summon、ring-with-gap 等，每個都有參數。
- 遊戲行為要和現在完全一樣；用回歸測試確認預設資料能重現目前的遊戲。

2. 簡單的 Maker 頁面，放在 games/survivor/maker/，適合小朋友、繁體中文，不做美術（沿用現有圖片、顏色或 emoji）：
- 編輯技能樹：幫流派和卡片改名、用滑桿和下拉選單選積木和數值、設定前置條件。
- 編輯敵人種類：數值，加上從積木選的攻擊。
- 編輯魔王招式。
- 驗證把數值限制在安全範圍內。
- 「試玩」按鈕用自訂資料開始遊戲。
- 「恢復預設」按鈕還原預設資料。
