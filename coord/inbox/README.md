# 公開需求摘要

本目錄與既有 done/ 已進 Git。新紀錄只寫適合公開的遊戲需求摘要；若原話含私人資訊或完整對話，留在 Mac Studio `~/.local/share/erin/inbox/`，不直接提交。

可公開紀錄沿用 kind: request|feedback|approve、lane: none、ref: 卡片 id、分隔線與內容。不要把 agent 的建議寫成家長已決定；只有家長明確授權才記 approve，並附所授權的完整 SHA 或清楚的範圍授權，不冒稱逐版核准。

舊歷史來源保留，不因流程整理批次刪除或重寫 Git 歷史。新的正式任務與規格放在 coord/tasks/，不以 inbox 或本機私人原文當另一套任務狀態。
