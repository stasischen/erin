# Maker 六分頁外殼交接

本卡依家長的統一拼圖第 2 步，只搬移操作介面；沒有遷移招式格式、調整平衡或改戰鬥引擎。

## 分頁與操作

| 分頁 | 左列項目 |
|---|---|
| 武器 | 水球、棒棒糖錘、糖果大劍，各自保留連段、聚氣與方向等原欄位 |
| 技能卡 | 流派名稱、每張卡（圖示、流派與前置關係提示）；卡片欄位、前置卡選擇與積木編輯仍保留 |
| 怪物 | 每隻怪物的造型、移動、身體數值、分階段攻擊與舊攻擊 |
| 老師 | 魔王階段、安全圈、各招式 |
| 關卡 | 出怪節奏、每關波次、精英怪、巧克力大熊 |
| 規則 | 預設設定（第一項）、碰撞與重量、中立道具、流派數值、基本玩法、流派共用、魔王共用 |

六個分類固定在頂端；左列選一個項目，中間只建立那個項目的控制項。列表與編輯各自捲動，不再把八隻怪物、全部武器和共用數值串成同一個長頁。技能卡左列保留流派及前置關係文字，編輯內仍能設定前置卡。

右側預覽預設收起，按「預覽」開啟；沿用既有 compact 尺寸旗標，短螢幕改成右側可收起的浮層。按「看這個積木的效果」也會開啟預覽。切換項目會關閉上一個預覽／練習場，避免持續留下場景。

每個項目上方都有「試玩」：武器與怪物開啟既有免傷練習場，帶入目前未儲存的草稿及選中 id；怪物原有「試這隻」也保留。卡片與老師單招開啟既有真實引擎效果展示，按「返回編輯」回來。流派名稱、老師階段、安全圈、關卡與規則則儲存後進入完整作品試玩。底部「試玩」仍是完整作品試玩。練習場不再佔用分類分頁。

Maker「預設設定」保存外層展開狀態，切換內部開關或重畫不會收起。玩家齒輪設定的控制區與底部操作列分佔空間，控制區有底部留白，可捲到最後一項。

## 已執行的驗證（Codex）

只執行 `node games/survivor/tools/test.cjs`，一般測試全數通過。更新原 Maker 操作測試，使其真的經過新分頁／項目選擇，再檢查：

- 只切換六個分頁不會改變作品資料；舊格式的載入／遷移測試繼續通過。
- 各武器、八隻怪物、卡片／前置卡、老師、關卡、規則可以修改、儲存及重新載入；武器同名欄位互不覆蓋。
- 規則頁所有數值滑桿具有中文標籤。
- Maker 預設設定切換及重畫後仍展開；預覽開關可操作。
- 試玩路由傳遞選中的武器／怪物與最新草稿；卡片、老師單招傳遞正確展示 id。
- 前置卡循環及儲存失敗仍阻擋完整作品試玩；恢復預設與返回入口保留。
- 版本 `20261026ab` 的所有頁面資源、預覽／練習 URL 與 Service Worker 快取一致。

以上是實作驗證，不是 Grok 審查。未執行 `--layout` 或瀏覽器上手操作。

## 交 Grok 的實際操作驗證

已將 `tests/levelup-layout.cjs` 改用新分類與項目入口，並保留測試目標 **1024×461、740×360**。請審查最後實質提交，執行版面測試並在這兩種尺寸親手操作：

1. 六分頁在上方、可切換；左列可到最後一項；每次僅編輯一個項目；每個面板最後一個控制項都可到達。
2. 開／關右側預覽，確認小螢幕能收起再編輯；怪物移速滑桿更新同一個即時場景。
3. 項目「試玩」、怪物「試這隻」、卡片／老師單招「返回編輯」均帶正確內容且能返回；切項目不殘留舊 iframe。
4. 展開規則第一項「預設設定」，連續切換音樂、搖桿跟隨、攻擊模式後仍展開。
5. 齒輪設定捲到底，最後一個控制項、恢復預設與完成按鈕都可觸及且不互相遮擋；確認直橫轉向。
6. 使用既有作品儲存／重新載入、試玩及返回 Maker，確認體感與玩法未變。
