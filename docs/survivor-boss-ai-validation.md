## 資料與共用規則

`engine/boss-ai.js` 提供不讀 DOM、Canvas、儲存、音效、時鐘或亂數的純函式：

- `phase(phases, hpRatio)`：依血量門檻取得階段。老師接合層逐階段轉場，保留喊話、閃光與轉場停頓。
- `scores(moves, rules, input)`：依招式 id、距離、可見性、階段與上一組招式篩選，再計分。`choose(rows, sample)` 接受外部 0～1 抽樣；沒有候選就回傳 `null`，不會為了出招而重複上一招。
- `start(timing)` / `advance(state, timing, dt)`：預備 `windup` → 出招 `active` → 收招 `recovery` → 冷卻 `cooldown` → 選招 `select`。每次最多進一個狀態，回傳可序列化的 `{type:'enter', phase}` 事件，掉幀不跳過完整預警。選招為即時操作，沒有額外等待秒數。

`boss.ai.rules` 為純資料招式清單，每個 id 最多一列。Maker「魔王 → AI 規則」可移出／加入招式、改權重／距離／角度及階段加權，也能調整階段血量門檻。權重 0 等同停用。招式本身的開始階段仍在該招觸發積木。

| 欄位 | 單位／範圍 | 意義 |
| --- | --- | --- |
| `moveId` | 已存在的招式 id | 穩定連結招式與圖示／未來動畫 |
| `weight` | 0～100 | 基本權重，預設 1 |
| `minDistance` / `maxDistance` | 0～10000 世界單位，含邊界 | 可用距離 |
| `angleWeight` | 0～10，預設 0 | 相對上次出招方向的朝向加權 |
| `phaseWeight` | 0～10，預設 0 | 每多一個血量階段的加權 |
| `offscreen` | 布林 | 是否允許畫面外使用；老師仍有原先遠距離招式保護 |

分數＝`weight × (1 + angleWeight × (1 + cos(angle)) / 2) × (1 + phaseWeight × (phase - 1))`。`angle` 是目標方向相對上次出招方向的弧度；共用函式不依賴老師外觀或動畫朝向。

老師保留舊近／中／遠招式分組及安全合招作為角色接合層；共用選招函式本身沒有這些角色限制。預設權重皆 1、角度與階段加權皆 0，所以原分組仍均勻抽選。上一組招式不再次選入；同一個「黑板擦連衝」招式內的數次衝刺仍保留，每次重新完整預警。

每招時機積木新增 `recovery`（0～3 秒）、`cooldown`（0～8 秒），舊作品未填自動補 0；原有 `warning`、`duration`、`pulse` 保留。老師整組招式冷卻取各招設定與原階段休息的最大值，避免合招繞過冷卻；收招不造成範圍傷害，畫面移除危險區並以像素亮點提示反擊。已射出的國字仍依原壽命飛行。落地原有反擊時間取共用收招與 `combat.leapRecovery` 較大值。

老師原本衝撞的生效時間仍由預告距離／招式速度換算；牆面時間仍至少足夠橫越原預告區；跟隨點名沿用資料中的跟隨＋鎖定秒數，且其他招式至少 0.6 秒預警。這些相容規則留在老師接合層，未改動既有戰鬥節奏。初登場與轉場仍沿用既有資料／流程。
