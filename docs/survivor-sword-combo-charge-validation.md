# 糖果大劍、連段與自動聚氣交接

來源：`coord/inbox/done/20261026T063539Z-parent-sword-combo-charge.md` 及家長後續修訂 `coord/inbox/done/20261026T064215Z-parent-sword-charge-revise.md`。蓄力依後者：只強化武器朝前招式，不做 360°，範圍脫困交給技能。本卡維持自動選最近敵人、自動攻擊；技能按鈕沿用原泡泡與流派效果。分支 `codex/survivor-sword-combo-charge`；版本 `20261026w`。commit、push、PR 由 erin-watch 代辦；本文件是實作與測試交接，審查由 Grok 進行。

## 可以試的玩法

- 開局第三把「糖果大劍」：100° 橫斬、反手斬、長直線重刺。重刺為基本傷害 2.5 倍、長度 120、半寬 18，額外擊退 30、前踏 12，額外收招 0.35 秒。衝刺結束會嘗試一次突刺，不受普攻冷卻阻擋；沒有可命中的敵人則不空揮。
- 大劍蓄力是長直線穿透突刺，長度 136、半寬 18、2.5 倍傷害，沿線敵人各命中一次；朝向仍依最近敵人。
- 水球：每第三發變成 1.5 倍大泡泡、1.6 倍傷害；首次命中或飛行結束時濺出半徑為泡泡半徑 2.5 倍的小水花，傷害為本球的 30%。直接命中的目標不重複承受這次水花。蓄力水球為 1.7 倍大、2.5 倍傷害，可持續穿透（最多 99 次額外命中，仍有飛行距離與每目標一次限制）。
- 棒棒糖錘保留第四下旋轉，第四下範圍 1.5 倍、傷害 1.6 倍；蓄力是前方 120° 大扇形重擊、範圍 1.7 倍、傷害 2.5 倍，附 0.8 秒暈眩及額外擊退。蓄力優先於第四下旋轉，蓄力即使受到多重攻擊卡加角度仍封頂 180°。重量縮放沿用共用擊退入口。
- 三把預設站定 1 秒聚氣完成；普通攻擊不清空未完成聚氣，下一次成功攻擊消耗充滿聚氣。移動開始時保留 35%，持續移動不繼續累積；Maker 可設 0（重置）至 1（全保留）。主角身上畫聚氣圈，頭上顯示連段數。充滿後的攻擊優先使用蓄力型態，仍推進連段。
- 連段計數在停止成功攻擊 1.1 秒後重置；普攻冷卻、暫停、目標超出範圍都不會偷偷消耗蓄力。暫停凍結計時，換關及重開清除連段與聚氣，持有武器仍依既有換關規則保留。
- 練習場加入大劍，三把武器皆可移動、衝刺、站定聚氣，統計列同步顯示連段與聚氣百分比。Maker 改參數沿用既有即時預覽更新流程。

這些數值是本次要求的可調試玩初值，手感與平衡交 Erin 試玩。

## 資料、Maker 與卡片

`data/defaults.js` 的每把武器新增下列數值，安全範圍由 `SurvivorData.ATTACK_BOUNDS` 驗證；Maker 分武器顯示適用欄位。

| 欄位 | 意義／單位 | 範圍 |
|---|---|---|
| chargeStun | 蓄力暈眩秒數 | 0–2 |
| comboEvery | 連段循環下數 | 整數 2–10 |
| comboReset | 未成功攻擊重置秒數 | 0.3–5 |
| comboMultiplier | 最後一段傷害倍率 | 1–5 |
| chargeSeconds | 站定充滿秒數 | 0.2–5 |
| chargeMultiplier | 蓄力傷害倍率 | 1–5 |
| moveRetention | 開始移動保留聚氣比例 | 0–1 |
| splashSize / splashDamage | 大泡泡水花半徑倍率／傷害比例 | 1–4 / 0–1 |
| comboSize / chargeSize | 最後一段／蓄力範圍倍率 | 1–3 |
| comboPush | 重刺／蓄力額外擊退，世界單位 | 0–100 |
| finisherRecovery | 近戰最後一段額外收招秒數 | 0–1 |
| stepDistance / thrustWidth | 大劍前踏／直線半寬，世界單位 | 0–40 / 5–50 |

`baseShape`、`comboShape`、`chargeShape` 是形狀 id；近戰普通與蓄力只接受 `sector`／`line`，最後一段另接受 `spin`，投射物只接受 `projectile`。蓄力不接受旋轉／圓圈。`direction` 可在 Maker 設 `nearest`（預設朝最近敵人）或 `facing`（朝移動面向），普通與蓄力共用相同方向規則。

`comboEnabled`、`chargeEnabled` 為布林開關；大劍另有 `dashThrust`。舊 `spinEvery` 仍接受並在缺少 `comboEvery` 時遷移，驗證後作為錘子 `comboEvery` 的鏡像；Maker 以連段下數作為唯一旋轉週期設定。舊二武器作品、未存武器欄位的作品、自訂錘子數值均可補上第三把及缺省值；不接受未知／重複 id 或不合法範圍。

所有卡補 `descriptionSword`；大劍讀取順序為此欄位 → `descriptionMelee` → `description`。Maker 可編輯大劍說明，匯入舊卡時補近戰說明。多重攻擊仍擴大扇形，穿透卡擴大近戰距離，風刃為近戰追斬，後射為後方斬擊，流派命中與技能沿用原系統。只限飛行投射物的「分裂」卡不會提供給錘子或大劍。

Maker 通用效果新增 `trigger: "combo"` 和 `comboStep`（1–10 整數，缺省 3）。成功攻擊第 N 下觸發一次，沿用既有積木間隔限制；沒有敵人或近戰無法命中時不觸發。既有卡配方不變。

## Godot §11 對照

- §11.1：武器新欄位與卡片說明都是可序列化資料，含安全驗證及舊 Maker 遷移。仍沿用 `defaults.js`，全面 JSON 抽離另卡。
- §11.2：`SurvivorEffectBlocks.attackTick/attack` 是輸入狀態、武器、dt、是否移動 → 新狀態與事件的純函式，不依賴 DOM、Canvas、真實時間或亂數。`SurvivorWeapons.swing/intersects` 負責攻擊形狀與幾何。
- §11.3：`weapon-attack` 帶武器 id、連段序號、finisher、charged；`weapon-swung` 帶形狀、角度、範圍、傷害、暈眩、擊退、踏步、收招等資料。接合層確認命中才提交狀態，繪圖只讀事件。沿用既有系統，未另建全域事件匯流排。
- §11.4：新增內建 8×8 大劍點陣圖示，沿用整數縮放。沒有新增外部素材；未匯出 PNG，保留 `icons.js` 原稿。
- §11.5：音效沿用既有 shoot/water，無新增音訊或匯出工作。
- §11.6–7：固定輸入測試保留可移植案例；規則採秒與世界單位，搖桿／鍵盤由既有輸入層接合。實體手機觸控、視覺辨識與安全區仍需 Grok 和 Erin 實測，尚未移植 Godot。
