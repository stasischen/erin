# 老師戰畫面外生成修正

依據：`coord/inbox/done/20261025T164331Z-parent-zone-summon-spawn.md`。版本：`20261026e`。作者 Codex；交 Grok 獨立審查。

## 行為

- 老師召喚、老師戰一般波次、Maker 小怪召喚都沿用 `spawnEnemy`，統一使用 `offscreenSpawn`；縮圈不再把生成位置限制在安全圈內。本紀錄取代前張安全圈驗證文件的圈內生成描述。
- 先從鏡頭四邊抽點，轉成環形地圖座標後，以 wrapped 最短距離重新檢查。敵人整個身體必須在鏡頭矩形外，另留 16 距離邊距；與主角中心至少相隔雙方半徑加 160 距離。老師本身同樣使用這個安全生成檢查。
- 遇到特大視窗或距離不足時，嘗試鏡頭中心與世界最遠座標的組合；都不安全就不生成，避免 wrap 回可見畫面。
- 小怪可從紫霧走向主角，紫霧只影響主角，敵人血量與移速照常；沒有改動敵人種類、數量上限或霧的傷害設定。
- 更新 version.json、入口與展示資源版本、Service Worker 快取。

## 驗證

執行 `node games/survivor/tools/test.cjs --layout`：版本檢查、25 組非版面測試全部通過，包含 153 組既有固定亂數快照。`levelup-layout.cjs` 的真實 Chrome 啟動收到 `SIGABRT`，整體退出碼 1；版面未驗證，需 Grok 在可啟動 Chrome 的環境補跑。`git diff --check` 通過。

新增 `tests/zone-summon-spawn.cjs` 覆蓋四種視窗、五種圈半徑（包含最小圈）、七種主角位置（包含接縫／角落），共 140 組一般波次與實際老師召喚路徑。獨立檢查整隻敵人與視野的間距、主角最小距離、合法地圖座標；另測超大視窗候選回圈／無空間時跳過、無安全圈、數量上限，以及霧外小怪追蹤速度與血量。更新舊 `boss-zone.cjs` 的圈內生成斷言為畫面外。
