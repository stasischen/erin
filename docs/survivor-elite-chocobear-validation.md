# 精英怪與巧克力大熊：實作交接

來源：`coord/inbox/done/20261025T170214Z-parent-elite-chocobear.md`。
分支：`codex/survivor-elite-chocobear`。作者 Codex；尚待 Grok 審查，沒有自行核准或上線。

## 遊戲行為

- 精英使用普通怪造型，預設 1.25 倍大小、5 倍血量，有光環與能力標籤。每 18 秒以 35% 機率抽選，最多同時 3 隻；每隻只有一種能力。
- 糖霜護盾完全擋住前 3 下，第 4 下才傷本體；破盾散成糖粒。分裂死亡後排入 3 隻同種類小怪（0.6 倍大小、0.3 倍普通血量），從畫面外走入，不遞迴變精英；沒有生成空間時等待。
- 加速光環讓 wrapped 距離 150 內的怪物加速至 1.35 倍。糖漿先有 0.6 秒淺色痕跡，生效後速度剩 65%，4 秒消失，最多 48 處。
- 傳送先閃爍並畫出固定落點，1.2 秒後傳送；落點距主角約 150，若玩家走近落點就取消。畫面外取消預告，暈眩時暫停能力。精英沿用普通怪招式，新增 0.8 秒出招提示。
- 每隻精英擊敗必定直接給 5 經驗並閃出金色粒子，不受寶石上限影響；在下一個安全更新點處理升級。
- 巧克力大熊每關在老師出場時間的 50% 出現一次，從畫面外走入。上方顯示名字與血條，盔甲階段加上「糖衣盔甲」；血條合計盔甲及本體血量，身上也有糖衣環與盔甲刻度。預設本體 450 血、盔甲 180 血，本體依關卡倍率增加；破甲那一下不穿透傷到本體。
- 重擊先在玩家當時的位置畫出固定影圈，1.2 秒後落地；沿用現有範圍危險判定，支援衝刺無敵與完美閃避。大熊畫面外或老師出場動畫期間不出招；離開畫面、死亡時取消大熊的預警。
- 打倒大熊後連續兩次三選一，第二次排除第一張，標題顯示目前第幾張；不消耗經驗、不增加普通等級、不額外補重抽次數。卡池用完則各次提供回血。第一張舊事件無法誤選第二張。
- 老師的出場時間維持原設定；大熊仍活著時也可進入老師戰，大熊不參加老師出場時的小兵聚合動畫。
- 新資料在 `data/defaults.js` 的 `elites`／`chocobear`；`data/schema.js` 定義數值界線與能力白名單。舊 Maker 作品缺這兩區時補預設，保留原設定。Maker「怪物」頁可切換兩類怪物、選擇精英能力、調整數值及大熊名稱；新按鈕採圓形點陣圖示。展示小場景不自動生成精英／小頭目。
- 版本升為 `20261026f`，同步兩個頁面、展示網址、Service Worker 版本與新引擎預快取。

以上頻率及數值為試玩初值，後續由 Erin 試玩決定是否調整。
