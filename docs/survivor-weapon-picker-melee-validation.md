## 起手與武器

移除起始精靈畫面。開場以兩個圓形純像素圖示選水球或棒棒糖錘，沿用點選預覽文字、確認、雙點及數字鍵操作。選武器不送卡、不指定流派、不消耗重抽。選擇期間遊戲時間停止；第一張取得的流派卡設定起始流派權重，主流派仍依持有的不同卡張數決定，同數量時偏好首次選的流派。沒有流派卡前維持藍色。每局三流派、每流派五張普通／稀有池、傳說機率、變身和合體規則保留；若先選中立卡，等第一次取得流派卡才設定流派。

水球保持原有自動遠程攻擊。錘子朝最近的可見敵人自動揮擊，初值：間隔 0.7 秒、扇形 120 度、距離 70 世界單位、傷害為水球基礎的 1.6 倍、額外擊退 15 單位、第 4 次為全周。敵人的碰撞圓與扇形相交就命中，一次扇形可打到多隻。沒有可命中的敵人時不空揮，不消耗第四下、蓄電或衝刺強化。每下會有持續 0.24 秒的扇形軌跡及移動的錘子像素圖；傷害在揮擊當下結算一次，軌跡不再判傷害。

持錘受到傷害乘 0.85；接觸、國字、危險區、Boss 招式共用既有傷害接合層，紫霧持續傷害也套用武器減傷，但不消耗一次性泡泡盾。藍色／薄荷綠／紫色及紫色火花沿用水球流派配色，合體卡呈現雙色。換關保留武器、已揮次數、卡池及成長；重開重新選武器、清除次數與特效。

## 卡片對應

| 效果 | 持錘時 |
|---|---|
| 大水球／水系變身／大水滴 | 放大揮擊距離；原有傷害倍率和大水滴額外擊退保留 |
| 連發／移動時加速攻擊 | 縮短揮錘間隔，以武器的 0.7 秒為基準 |
| 多重水球 | 依原多發角度增加扇形角度，最多一整圈 |
| 穿透水球 | 扇形本來就能命中多隻，改為每級增加 10% 揮擊距離 |
| 風系普攻 | 按原速度加成倍率增加揮擊距離 |
| 風刃 | 命中後對範圍內另一隻敵人追加一次近距離追斬，沿用風刃傷害及連接距離上限，不額外發射水球 |
| 濺水／水窪／濕答答／跳電／蓄電 | 命中時沿用原有效果、倍率、濕狀態與擊倒計數；範圍、閃電仍受可見範圍保護 |
| 後射 | 增加後方扇形；全周攻擊不重複結算 |
| 衝刺後強化下一發 | 改為強化下一次可命中的揮擊，沿用期限、大小及傷害倍率 |
| 彈牆、分裂水球 | **目前沒有錘子本體的近戰效果**，仍留在原卡池；選卡說明會註明僅改變飛行水球，不新增未經要求的近戰機制 |
| 其他中立、技能、衝刺、被動及 Maker 積木 | 保持原效果；命中積木由揮擊命中觸發，自訂發射／召喚積木仍可產生獨立水球 |

升級畫面及已持有卡片的展示會傳入目前武器，持錘時以近距離假怪示範真實揮擊。設計室單獨展示未指定武器時沿用水球。上述特殊對應卡會顯示近戰說明；彈牆與分裂的近戰延伸若要做，留給 Erin 與家長決定。

## 資料、驗證與移植 Godot §11

- §11.1：`data/defaults.js` 新增可序列化 `weapons` 登錄表，使用穩定的 `water-ball`、`candy-hammer` id。沒有 weapons 的舊作品補預設，保留其他作品資料；schema 只允許既有兩種種類及有限數值。沒有改為 JSON 載入，沿用既有 defaults 結構。
- Maker「數值」新增八個錘子參數：interval 秒（0.2–2）、arcDegrees 度（30–180）、radius 世界單位（30–150）、damageMultiplier 倍（0.5–3）、push 世界單位（0–60）、spinEvery 次（整數 2–10）、damageReduction 比例（0–0.5）。資料檔的描述為預設說明，選武器畫面會由當前數值顯示間隔、旋轉次數及減傷。
- §11.2、11.3、11.7：`SurvivorWeapons.swing/intersects/receivedDamage` 為純規則；明確傳入次數、角度、數值與相對世界座標，不讀時間、DOM、Canvas 或亂數。`weapon-swung` 結果含 weaponId、次數、角度、扇形、半徑、傷害、擊退；接合層另傳可序列化位置、色彩 id 到既有 vfx。沒有新增共用事件匯流排；卡片命中／傷害仍接既有全域狀態函式。
- §11.4、11.5：新增共用 8×8 格點（映射為 16×16）的錘子圖示，靜態持錘和揮擊共用；`render/weapons.js` 獨立處理繪圖，不負責傷害。沒有新外部素材或音訊，沿用射擊音效；PNG／音檔匯出未在此卡製作。
- §11.6：`tests/weapons.cjs` 記錄固定扇形邊界、後方與全周、間隔、傷害、空揮不消耗、卡片／雙色／跳電、衝刺強化、減傷、畫面外與出場保護、Boss 最後一擊、換關／重開、池上限、舊作品及錯誤值。另測真實錘子展示與 Maker 控制項儲存／重載。現有水球回歸繼續執行。
