# 身體柔性分離交接

來源：[家長核准需求](../coord/inbox/done/20261026T043448Z-parent-body-separation.md)。版本 `20261026q`。

主角與活著的小怪、精英、巧克力大熊、可見老師會逐幀推開；深度重疊會分數幀消解到剛好接觸，避免瞬間跳位。整群怪推主角共用每秒 12 世界單位上限，敵人每幀推移不超過其原半徑的 0.45 倍或每秒 720 單位。衝刺最後一幀以及衝刺保護時間可穿過敵人；完美閃避的額外護盾期間也可穿過，普通受傷無敵不會停用分離。

一般怪質量為 1，坦克行為（預設布丁）與巧克力大熊為 8，老師為 40。重型怪分擔較少推移，對主角推力較大；主角自己走入重型身體時，沿移動線段退回首次接觸點，包含跨接縫與一步穿越的情況。回退自己的移動不算怪群推移預算。老師身體不被推移，避免改變既有預警衝撞路線。老師登場吸入期間暫不分離。

`bodySeparation` 是可序列化設定，Maker「敵人／怪物身體碰撞」可調整：

| 欄位 | 預設 | 範圍／單位 |
| --- | --- | --- |
| enabled | true | 開關 |
| radiusScale | 1 | 0.5–1.5，分離半徑倍率；不改傷害範圍或圖像 |
| playerForce | 1 | 0–1，主角與怪物的修正比例 |
| enemyForce | 0.25 | 0–1，怪物彼此的修正比例 |

以上是可調的工程初值，手感仍交 Erin 試玩確認。舊作品缺欄位時補預設；非法布林、非有限數字及超出範圍會被拒絕。原本的 `bodyContact` 傷害倍率與「只推開」設定獨立保留；碰撞傷害仍先判定，再做位置分離，不會因身體被推開而意外停用碰撞傷害。關閉新分離時保留舊坦克與「只推開」路徑，後者仍讓衝刺穿過。

`SurvivorBodies.solve` 傳入設定、秒數、環形世界、視窗、前一位置、穿越旗標與身體資料，回傳新位置及候選檢查數；不修改輸入，不讀 state、DOM、Canvas、亂數、時鐘或儲存。接合層只套用位置與更新鏡頭，不改攻擊原點、方向、招式階段、事件佇列或生成入口。格子以最大身體直徑選尺寸，只訪問相鄰九格，每隻最多檢查 32 個後續候選者，總候選檢查數上限為 32 × 身體數；高密度重疊逐幀消解，不保證單幀全部分開。原本完全在畫面外的敵人不能靠分離位移進入可見範圍，仍須正常行走進場。生成、包圍事件和果凍分裂沿用原入口。

執行 `node games/survivor/tools/test.cjs`，未執行 `--layout`。新增測試覆蓋固定輸入／不修改輸入、逐幀到接觸點、零距離、密集怪群推移與計算上限、大怪擋路、衝刺穿越與額外保護、受傷無敵仍分離、環形接縫、畫面外保護、預警資料不動、舊作品遷移、驗證與實際 Maker 控制項儲存重開。既有包圍、果凍分裂、生成、Boss 招式與快取測試亦由同一指令執行。

舊 153 組快照不重錄，改為在新分離關閉時驗證相容玩法；新預設開啟時另比較普通與 Maker 模式的同一組固定輸入輸出。舊環形追逐方向測試暫關分離，以隔離追逐方向；開啟時的跨接縫分離由新測試覆蓋。老師進場測試將主角推力設零，保持該測試的固定鏡頭前提。
