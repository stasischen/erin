# 水／風／雷流派改版交接

依據：[家長收件匣](../coord/inbox/done/20261025T183119Z-parent-school-redesign.md)。版本 `20261026g`，尚未核准上線。本文件記錄實作與工程驗證，正式程式審查由 Grok 執行。

## 可試玩的內容

- 開始與重新開始先選起始精靈，使用既有圓形點陣圖示／預覽／確認介面；支援觸控、雙點與 1–3 鍵。選擇期間世界停止，得到對應攻擊卡並提高該流派權重；換到第二關保留本局選擇，不重選精靈。
- 每個流派有 7 張普通／稀有卡、1 張傳說及 1 張終極；另外保留 9 張通用卡、3 張雙流派卡，共 39 張。新增 15 張卡與各自點陣圖示，預設流派卡不再要求固定前置順序。
- `schools` 登錄表支援 N 個流派，每局抽 3 個。各從 7 張普通／稀有卡抽 5 張，整局固定，重抽及換關不重新洗卡池。起始攻擊卡為額外贈送，若已在池中不重複取得；傳說與終極不占這 5 張。
- 張數計算不同的單流派卡，重複升級不增加張數，雙流派卡不計入任一邊門檻。3 張變身、5 張開放該流派終極；雙流派卡要求兩邊各 2 張。可同時取得多種終極，各有獨立冷卻與畫面。
- 普通／稀有卡依本局卡池抽選；傳說卡每次選卡另外擲一次預設 2.5% 的入池機會（每張獨立），不保證某一局會遇到。稀有權重 0.55；同流派每張已持有卡增加權重 0.65，起始流派額外 +1.5。這些是工程初值，並非傳說卡最後顯示機率。
- 原有卡片等級上限保留 5，新卡預設只選一次，避免重複取得沒有進一步效果的機制卡；Maker 可調整上限。三種流派可混搭，主流派按不同卡數決定，同分優先起始流派，其餘按本局抽選順序。
- 水球依主流派呈藍／薄荷綠／紫色，雷帶火花；有雙流派卡時使用該卡兩色漸層，多張雙流派卡時按資料順序取第一組。變身加光環，水變半透明並加大水球、風長翅膀並多一格衝刺、雷有環繞火花並增加連鎖距離。
- 噴泉／吹飛定期推開附近敵人；泡泡盾擋一次直接攻擊（含老師與自訂危險區，不抵銷環境紫霧）；順風退半格回充進度，不能拿半格發動一次完整衝刺；雷步用整段路徑判定避免高速穿漏。風牆推開接近敵人並擋敵方子彈；下雨全場緩速但不造成畫面外傷害。
- 蓄電按本局擊倒數累計，下一輪普攻消耗一次充能；多重水球同輪一起增強。風刃提供一次穿透後產生短程風刃，風刃不再衍生風刃。避雷針固定在放置位置、受數量與生命期限制。

## 資料與 Maker

新設定都在 `data/defaults.js` 的 `schoolRules`，Maker「數值 → 流派與精靈數值」提供繁體中文滑桿。預設值在該資料檔，安全範圍／步進由 `data/schema.js` 的 `SCHOOL_BOUNDS` 統一定義並供 Maker 共用。卡片品質可在卡片編輯頁調整。

| 欄位群 | 意義與單位 |
|---|---|
| `schoolsPerRun`、`cardsPerSchool`、`transformCards`、`ultimateCards`、`fusionCards` | 流派／不同卡片的整數張數，預設 3／5／3／5／2。 |
| `legendaryChance`、`rareWeight`、`ownedWeight`、`starterWeight` | 傳說入池機率 0–1，及無單位抽選權重。 |
| `bigDropEvery`、`bigDropSize`、`bigDropDamage`、`bigDropPush` | 發射輪數、大小倍率、傷害倍率、世界單位擊退距離。 |
| `fountainSeconds`、`fountainRadius`、`fountainPush`、`wetSeconds`、`wetDamage`、`rainSeconds`、`rainDuration` | 噴泉間隔秒、半徑、推開距離、濕潤秒數、額外傷害比例、下雨間隔秒／持續秒。 |
| `windBladeDamage`、`windBladeRange`、`gustSeconds`、`gustRadius`、`gustPush` | 風刃傷害比例／飛行距離，吹飛間隔秒／半徑／推開距離。 |
| `refundCharge`、`lightSpeed`、`lightMagnet`、`eyeWait`、`eyeRadius`、`eyePush` | 回充格數、移速與拾取半徑加成比例、風牆等待秒／半徑／每秒推力。 |
| `chargeKills`、`chargeDamage`、`rodSeconds`、`rodDuration`、`rodRadius`、`rodDamage`、`rodTick` | 蓄電擊倒隻數／傷害倍率，避雷針間隔秒／持續秒／半徑／傷害／攻擊間隔秒。 |
| `thunderStepStun`、`staticSeconds`、`staticDamage`、`superconductorJumps` | 雷步暈眩秒、靜電間隔秒／傷害、超導體額外跳數。 |
| `waterFormSize`、`windFormCharges`、`thunderFormRange` | 變身後大小加成比例、額外衝刺整格數、連鎖距離加成比例。 |

所有半徑／距離均為遊戲世界單位，不依 CSS 或 DPR 改變。原有緩速、濺水、傷害、技能、痕跡與終極數值仍使用 `tuning`、`build`，沿用既有 Maker 控制。

舊 schemaVersion 1 作品依穩定卡片 id 補入新卡與設定，保留自訂名稱、數值及積木；缺少品質欄位的舊流派卡移除舊前置鎖以採用新抽卡規則。新作品仍可在 Maker 自訂前置條件。通用卡、敵人、老師招式與關卡資料的驗證維持原限制；不接受任意增加未知卡 id 或修改登錄表。將來擴充流派時，在預設資料新增 `schools`、對應 `build` 名稱／色碼及卡片，毋須把抽選程式改成四個固定流派。

## 工程驗證

已執行 `node games/survivor/tools/test.cjs --layout`：29 個檢查腳本中，版本檢查及 27 個非版面腳本通過；版面腳本啟動 Chrome 時 `SIGABRT`，因此完整命令回傳失敗，未宣稱版面通過。

新增 `tests/school-redesign.cjs` 覆蓋固定抽樣輸入、N 選 3、每局固定卡池、任意順序／不同卡片門檻、變身事件只觸發一次、抽選權重、傳說額外機率、起始選擇、全部新機制、雙色／變身數值、同時終極、換關保留及舊作品遷移。也檢查高速衝刺整段路徑、物件池回收後不殘留大水滴／雷電屬性、靜止風牆與移動解除、畫面外下雨不造成傷害。

既有 153 組玩法快照保留原 24 卡及老師招式作回歸，其中 9 組因水窪與合體卡改為能獨立生效、旋風技能及零級連鎖係數修正而更新；其餘 144 組不變。新 15 卡另由新規則測試與既有 98 個獨立預覽場景驗證。`--layout` 已加入各尺寸的起始精靈圓形圖示／觸控確認，以及移除舊前置卡假設。

嘗試補做真實瀏覽器驗證時，本機 HTTP 伺服器綁定 `127.0.0.1:8000` 被沙盒以 `Operation not permitted` 拒絕；瀏覽器工具也依 URL 政策拒絕 `file:`。沒有繞過限制，尚無本版截圖或實機版面證據。

待 Grok／Erin 在可用環境補做：

1. 執行完整 `--layout`，確認 412×915、384×832、915×412、800×360、732×310、1024×768 的起始與升級畫面。
2. iPad 上確認起始三精靈、雙手操作、傳說金光、三種變身與雙色水球都清楚，敵方文字子彈容易辨識。
3. 各選一種精靈試玩，確認前期抽卡、傳說稀有度、回充與老師戰難度；工程數值是否喜歡由 Erin 決定。

## Godot §11 對照

- §11.1：新設定／卡片／登錄表皆為可序列化資料，放在既有 `data/defaults.js`；有範圍、單位、缺省與舊資料遷移。沿用 schemaVersion 1 的擴充欄位，尚未把全遊戲資料改為獨立 JSON 檔。
- §11.2、§11.6：`engine/schools.js` 的抽樣、資格、張數、權重、外觀選擇、射擊特性、路徑距離與成長事件皆為純函式；亂數抽樣值由外層傳入，測試保留輸入→輸出。既有傷害、計時與效果接合層仍使用遊戲狀態，未全面重構。
- §11.3：成長回傳僅含 `type`、`schoolId` 的 `transformed`／`ultimate-unlocked` 事件，由 `school-combat.js` 接合層更新充能、文字及特效；沒有 DOM／Canvas 物件跨事件。未另建全域事件匯流排。
- §11.4：新增圖示沿用 16×16 共用程式點陣；精靈、光環與天候沿用程式繪圖來源，沒有外部素材。PNG／sprite sheet 匯出仍是既有待辦。
- §11.5：沿用既有合成音效參數，沒有改音樂或新增音檔；音訊匯出仍是既有待辦。
- §11.7：新增範圍、擊退、飛行距離及冷卻使用世界單位與秒；抽卡規則不查 DOM，觸控與預覽維持平台接合層。整體引擎尚未完全分離，不宣稱已可直接移植。
