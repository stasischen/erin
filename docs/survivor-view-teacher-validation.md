# 固定面積視野與老師追擊戰交接

來源：`coord/inbox/done/20261026T120256Z-parent-view-teacher.md`。版本：`20261026al`。

## 行為與可調整資料

- 可見世界面積固定為 320000（800×400）平方世界單位，依裝置比例分配長寬。先算 `raw = sqrt(cssW*cssH/320000)`，顯示 zoom 向下取四分之一倍；使用相同比例的內框留邊，避免取整後平板仍能看到更多世界。Canvas backing store 仍依 CSS 大小與 DPR 建立。
- `state.width/height` 是內框世界大小；`screenWidth/screenHeight`、搖桿及 HTML HUD 是 CSS 像素。手動瞄準先扣留邊，再除 zoom；練習場沿用同一換算。純效果展示保留獨立鏡頭構圖。
- 地圖固定為以 4096×MAP_SCREENS 為基礎、地磚整數倍的環狀世界；旋轉或更換裝置不放大地圖。生怪與可見性仍依世界內框判斷。
- 老師階段移速預設 70／90／110；距離超過 800 世界單位時 2 倍快走，附藍色汗滴與提示。預警與出手依然站定。離開畫面不取消已預警的招式；閒置時只選跳躍／狙擊拉近壓力，邊緣箭頭沿用。
- 近距離 ≤200 用範圍／落地招，中距離用扇形、短牆與衝撞；遠距離 ≥600 或老師在畫面外用跳躍／狙擊。避免接連同招，沒有新選項時才重複。
- 血量＝（基本血量＋本局已升級次數×350）×關卡倍率。45～60 秒是待實際試玩的平衡目標，並非已量測達標。
- 第二階段起國字／粉筆速度 200／240，衝撞距離 450；第三階段休息 0.6 秒。
- 安全圈初始半徑 600，三次縮至固定半徑 180（基準短邊 400×0.45），每次預告 4 秒；圈外每秒扣 4 血，旋轉不改大小。
- 新形狀均經既有老師五積木白名單進入引擎：跳上講台（紅圈鎖定當下位置、1 秒起手、空中弧線、落地傷害與擊退、0.8 秒星星反擊窗）、粉筆狙擊（紅線跟隨 0.8 秒、單發速度 420）、黑板封路（兩側短牆留上下出口，3 秒）、黑板擦連衝（第二階段 2 次、第三階段 3 次，每次重瞄與完整預警）、點名追蹤（跟隨 1 秒、鎖定 0.5 秒）。
- 收件匣同時要求「連衝 0.5 秒」與「預警最短不低於 0.6 秒」，依後者採 0.6 秒。
- 新數值在 Maker「老師」的魔王階段、安全圈或各招式積木可調。點名追蹤的起手由「跟隨秒數＋鎖定秒數」決定；黑板封路的「範圍」是半牆長，「距離」是左右牆與中心間距。新欄位缺省會遷移，原有招式數值與積木仍保留。
