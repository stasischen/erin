# 生存武器與維護入口

一般生存以水球直接開局，最多同時裝備三把，各把有自己的攻擊間隔、聚氣與連段。升級仍是三選一；只要還有合法武器取得／升級選項，至少一格為武器。三槽滿後不再提供未持有武器，已持有武器升至五級後停止提供。共用專長與原有三種元素合體仍保留；合體依原規則，雙學派各取得兩張，不是把武器升滿即可合成。

Boss 試煉開場選一把原有水球、糖果錘或糖果劍，使用手動攻擊。新九把只供生存玩法，不修改原有三把的 Maker 武器編輯格式，也不新增存檔格式。

## 命中與共用專長

- 原三把沿用原有命中型卡片語義。錘劍武器等級的波與共用水花合成一次較大波，不疊成兩次附傷；三向劍氣交叉時每個敵人只承受一次附傷。多重近戰與後射也共用主命中清單，不重複主擊。
- 新九把每次施放或每輪持續脈衝最多觸發一次水花、學派附傷及 Maker 命中積木；這些二次傷害不再觸發同類卡片。旋風、噴泉與線束重疊時，同輪每個敵人只計一次直接傷害。
- 同一顆糖豆不回打已撞過的敵人；同一枚甜甜圈去程、回程各可命中一次。雷雲與小蜂同輪挑不同目標，低怪量不集中重複點名。
- 加大與攻速套用每把武器；多重增加覆蓋數量，吸管增加寬度；穿透對水球／冰刺加穿透，對其他武器延伸距離。後射、分裂仍明標原三把／水球用途。全局跟班、終極、回血、擊殺計數不會因三把武器而複製三份。
- 一般敵群以基本怪為主，少量特殊怪，環包事件保留相鄰兩側的撤退空間；Maker 自訂敵池維持原抽樣。

## 改哪裡

| 要改的內容 | 來源 |
| --- | --- |
| 武器名、類型、每級數值、武器說明 | `engine/weapon-catalog.js` |
| 三槽、等級、獨立計時、原武器接合、武器候選 | `engine/loadout.js` |
| 移動體、定點區、線束／點名與一次觸發規則 | `engine/weapon-attacks.js` |
| 新武器黏土形狀 | `render/weapons-survival.js` |
| 共用水風雷形狀與色票 | `render/effects.js`、`art-manifest.js` 的 `elements` |
| 共用專長分級公式 | `engine/effect-blocks.js` |
| 卡片與配裝文字／排版 | `engine/upgrade-info.js`、`ui/upgrade-view.js`、`upgrade.css` |
| 原抽卡、重抽、確認與恢復遊戲 | `ui/levelup.js`、`engine/schools.js` |
| 一般生存／試煉／作者試玩的模式邊界 | `engine/mode.js` |

以上路徑以 `games/survivor/` 為起點。Maker 的「試玩生存配裝」儲存並驗證目前作品，以同一作品進入隔離三槽試玩；「試玩」仍保持原單武器流程。新九把會使用目前作品的共用基礎傷害、攻速、尺寸／射程與學派規則；獨立五級表集中在 catalog，尚未提供每個獨立欄位的 Maker 編輯介面。不把試煉或試玩模式寫回玩家的攻擊偏好。
