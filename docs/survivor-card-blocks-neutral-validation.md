## 規則與相容性

十張卡沿用 feature id、power 合併封頂與舊作品欄位；共用公式、條件及動作放在 `engine/effect-blocks.js`，以 `{ref:'neutralRules.…'}` 讀原數值。新增 min／floor 運算保留金庫取整及上限。王冠沿用已完成的 modifier，積木檢視共用相同公式。Maker「技能卡」可收合、預覽與調整共用數值，使用原 NEUTRAL_BOUNDS 邊界與中文名稱；後射沒有新增可調數值。

| 卡片 | 保留行為 |
|---|---|
| item-wall | 非零方向才推動合法目標；沿路第一隻可互撞小怪，雙方各一次傷害並共用短冷卻；老師只受推動，不互撞、不遞迴。 |
| item-candy | 擊倒時嚴格小於機率才掉炸彈，上限 12；倒數到時先移除，再依原順序傷害半徑內可攻擊目標。連鎖新炸彈下次更新才倒數。 |
| item-bird | 每秒 2.5 弧度環繞，找範圍內最近合法目標；成功攻擊才重設間隔，每次更新至多一次。 |
| item-bank | 每顆寶石球加一，不按 XP 值；每指定顆數成長，floor 計算並保留上限，傷害與王冠相乘。 |
| item-split | 原水球只分裂一次，兩顆對稱碎片保留速度與 hitList；碎片不再分裂，不套自訂積木子彈，保留總彈數上限。 |
| item-magnet | 與風輕盈、支援磁鐵相乘；拾取與顯示半徑使用同一倍率。 |
| item-crown | 傷害乘原加成，最大血量扣原數值、至少留一點；取得時沿用原血量限制。 |
| item-clover | 首次取得帶此 feature 的卡加一次重抽，之後不加；原稀有權重倍率、抽樣及選卡次序不變。 |
| item-rear | 複製本次第一顆非自訂水球，向後射一顆、原傷害與外觀，保留彈數上限。 |
| item-cookie | 持有後才累積擊倒，每指定次數補一；保留滿血限制與死亡只結算一次。 |

條件／公式是純規則；原接合層仍負責持有判斷、目標排序、環繞座標、世界狀態、正式傷害入口及表現。死亡獎勵仍先餅乾再炸彈。沒有新增事件匯流排。遊戲、預覽、練習場 URL 與 Service Worker 快取同步升版。
