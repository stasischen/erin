# 共用回饋積木與觀察工具交接

來源：`coord/inbox/done/20261026T112942Z-parent-feedback-block.md` 與追加的 `20261026T113040Z-parent-feedback-block-addendum.md`。統一拼圖第 7 步。

## 資料與行為

武器五種招式、小怪分階段／等級攻擊、老師各招式，使用相同的 `blocks.moves[].feedback` 白名單：

| 欄位 | 意義／允許值 |
|---|---|
| `cue` | 原招式的穩定表現 id，保留舊作品；不任意替換攻擊種類 |
| `warningStyle` | `original` 原樣、`outline` 外框、`pulse` 閃動 |
| `slash` | 顯示刀光／分階段招式生效圖像；不改傷害與判定 |
| `hitStop` | 頓幀強度 0–2；基準 0.05 秒，重擊乘 1.5 |
| `shake` | 震動強度 0–2；近戰基準 2 格、0.12 秒，老師出招沿用原基準 |
| `sound` | `shoot`／`warning`／`hit`／`water`／`lightning`／`none` |
| `hint` | 招式文字、階段標記、主角蓄力／連段及瞄準提示 |

Maker 主角、小怪、老師共用編輯器。積木為主資料，驗證後產生執行接合資料；表現不修改攻擊形狀、傷害或時機。玩家設定的回饋開關／強度、震動與音效開關仍在外層套用。

舊的兩欄回饋積木會補預設；沒有積木的舊作品也可載入。近戰保留原頓幀與震動；水球、劍波與敵人原本沒有頓幀的招式預設為 0；老師原有出招震動預設倍率 1。存檔 schemaVersion 仍為 1，使用缺省遷移，不丟棄作品。資源與 Service Worker 版本為 `20261026ak`。

## 預覽與練習工具

兩種 iframe 沙盒都有可收合的「觀察工具」：1×／0.25×、凍結、判定框、身體圓、擊退箭頭、前後殘影、生怪 1／5／20 隻。工具狀態不寫入作品或正式玩家設定。凍結不推進模擬，仍可操作工具。生怪沿用正式種類與數量上限，再放到可見位置；練習場新增的對手沿用正式行為。

開啟殘影後先播放，按「保留調整前殘影」再改數值：橘色保留調整前軌跡，綠色累積目前軌跡；每份軌跡最多 600 個圓。Maker 更新／重建同項預覽時保留工具與對照；「清除殘影」可重新取樣。這是實際位置的軌跡對照，並非雙引擎同時播放。箭頭顯示持續擊退方向及即時推拉事件。
