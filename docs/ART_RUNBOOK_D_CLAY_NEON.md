# 美術 Runbook：D 黏土角色＋霓虹特效

版本 1.1（2026-11-01，依 D1 實作回報裁定 5 點）。設計稿由家長在 Claude 畫布上確認（「小怪獸 美術設計稿」D 排三張）；Codex 看不到畫布，**以本文件為準**。
本方向取代 `coord/tasks/specs/art-direction-v1.md` 的 A／B／C 像素方向；`../erin-art/STYLE_GUIDE.md` 的像素規則（1px 外框、32 色鎖定、禁止半透明、nearest）**不適用於 D**。
流程照 `docs/ART_FAST_TRACK.md`：只改允許的檔案、家長看截圖驗收、不走 Dot／Luna／Grok。

---

## 0. 總原則

1. **角色是黏土，危險和回饋是霓虹。** 角色不發光（只有一圈細輪廓光）；子彈、預警、寶石、命中、HUD 線條發光。玩家要一眼分出「怪物」和「危險」。
2. **先用程式畫黏土**（漸層＋光澤），載入時預先畫進離屏 canvas 當圖片用；之後才考慮換 3D 渲染圖。換圖時只換 art-manifest 的 sheet，遊戲碼不動。做法：world.js 等呼叫端只呼叫 `render/art.js` 的「畫角色（id, 姿勢）」；art.js 看 manifest 的 sheet，有圖就畫圖，`sheet: null` 就交給 SurvivorClay。呼叫端不直接呼叫 SurvivorClay。
3. **不改玩法。** hitbox、速度、傷害、AI、出招時序都不動；動作只是讀現有狀態（idle／run／windup／active／recovery／hurt／stun）來決定姿勢。
4. **效能底線**：iPhone／iPad Safari 上 200 隻怪維持 60fps。D1～D6 先用 Mac Chrome 量（200 怪平均 60fps、p95 ≤ 17ms 即可），iPad 實機在 D7 統一驗。每幀禁止 `shadowBlur`、`filter`、新建漸層；發光一律用預先畫好的光暈圖＋`globalCompositeOperation = 'lighter'`。

## 2. 黏土角色規格

座標單位：**1em = 角色寬度**。每個部件 = 一個橢圓，填「黏土漸層」：
`radialGradient(圓心在部件左上 30% 26%)`：亮點 → 主色 → 暗色，依序約 0–5%、30–50%、100%。
陰影：腳下橢圓 `left .12 / 寬 .76 / 高 .13`，`rgba(0,0,0,0.45)`。
輪廓光：整個角色外圍 1–2px 外光，色碼見各角色。
畫的順序：陰影 → 腳 → 身體 → 手 → 頭 → 臉 → 五官。

### 主角 小水滴（寬 64px、高 1.25em，輪廓光 `#78cfff`）
| 部件 | left | top | w | h | 漸層（亮→主→暗） |
|---|---|---|---|---|---|
| 腳 L／R | .29／.52 | 1.07 | .19 | .13 | `#c9936b → #5a3a2b` |
| 身體 | .25 | .72 | .50 | .42 | `#78cfff → #388de6 → #2464bb → #183b70` |
| 手 L／R（轉軸在上方 15%） | .13／.71 | .76 | .16 | .24 | `#d6f6ff → #78cfff → #388de6` |
| 頭（連帽） | 0 | 0 | 1 | .86 | `#ffffff → #d6f6ff → #78cfff → #388de6 → #2464bb` |
| 臉 | .17 | .27 | .66 | .53 | `#fff6ea → #f0cfa4 → #c9936b` |
| 眼 L／R | .32／.59 | .44 | .09 | .14 | `#383349`，左上小反光 `#9a95b0` |
| 腮紅 L／R | .24／.65 | .61 | .11 | .06 | `#f5a1bc` |

### 巧克力熊（菁英 96px／熊王 240px，高 1.32em，輪廓光 `#ff6a3d`）
腳 L／R `.22／.55, top 1.15, .23×.14`；身體 `.17, .68, .66×.54`；肚子 `.33, .80, .34×.30`（淺色）；手 L／R `.03／.77, .74, .20×.32`；耳 L／R `.07／.65, .01, .28×.28`；頭 `.02, .08, .96×.72`；口鼻 `.32, .44, .36×.25`；鼻 `.44, .46, .12×.08 #383349`；眼 `.26／.66, .34, .08×.12`。
棕色漸層 `#f0cfa4 → #c9936b → #936246 → #5a3a2b`；淺色部件 `#fff6ea → #f0cfa4 → #c9936b`。

### 果凍史萊姆（44–46px，高 .9em，輪廓光 `#bf83ff`）
身體 `0, .10, 1×.72`，上寬下扁的水滴形；漸層 `#ffffff → #ffd3df → #f5a1bc → #c2607f`；眼 `.30／.61, .38, .09×.14`。

### 布丁（46–48px，高 1em，輪廓光 `#bf83ff`）
本體 `.08, .30, .84×.60` `#fffbe6 → #ffe08a → #ffa94d`；焦糖頂 `.13, .14, .74×.30` `#f0cfa4 → #936246 → #5a3a2b`；眼 `.31／.61, .55, .08×.12`。

### 其他怪物
沿用同一套做法：1–3 個橢圓部件＋黏土漸層＋兩顆黑眼睛。新怪在 `render/clay.js` 加一筆設定，不寫新繪圖函式。

## 3. 動作（擠壓與拉伸）

整個身體以**腳底中心**為原點變形；不另外設計新的圖，每個姿勢都是同一組部件改位置與角度。實作上在載入時把每個姿勢（含 recovery 過渡的幾個中間樣本）預先畫成圖、遊戲中依狀態選圖，這是正確做法。

| 遊戲狀態 | 姿勢 | 身體變形 | 手 | 腳 | 眼 |
|---|---|---|---|---|---|
| idle | 待機 | 每 0.8 秒輕微上下 `scale(1.03,0.97)` 來回 | 向外 12° | 著地 | 張開 |
| run | 走路 1／2 交替，每 180ms 換一次 | 上移 .03em、傾斜 ∓5° | 擺動 ±25° | 輪流抬起 .07em | 張開 |
| windup | 蓄力 | `scale(1.12, 0.86)` | 舉起 140°（向外上方） | 著地 | 張開 |
| active | 出招 | 上移 .07em、`scale(0.90, 1.14)` | 前揮 −60° | 著地 | 張開 |
| recovery | 回到待機，150ms 緩動 | — | — | — | — |
| hurt | 受擊 | 右移 .05em、傾斜 10°，**閃白 1 幀**（疊白色 lighter） | 70° | 著地 | 閉眼（兩條斜線） |
| stun（只在該角色本來就有暈眩狀態時，例如 Boss／怪物；玩家目前沒有，不為此改引擎） | 暈眩 | 同 hurt，頭上轉三顆小星 `#ffe08a` | — | — | 閉眼 |

史萊姆／布丁沒有手腳：run = 左右傾斜 ±5° 交替；windup／active 同上表的身體變形。

## 4. 霓虹特效

做法：每種光暈在載入時畫成一張小圖（中心白、外圈主色、邊緣透明的放射漸層），每幀用 `lighter` 疊上去。

| 物件 | 規格 |
|---|---|
| 水滴彈 | 長 42px、寬 8px 圓角條，尾端透明 → `#78cfff` → 頭端 `#ffffff`，外光 `#35b9ff` 12px，沿飛行方向旋轉 |
| 經驗寶石 | 11px 正方形轉 45°，`#70e7ba`，外光 10px |
| 攻擊預警圈 | 3px 實線 `#ff6a3d`，內填 `rgba(255,106,61,0.12)`，外光 18px；內圈 2px 虛線 `#ffa94d`。windup 期間由暗漸亮，active 瞬間全亮並閃白 1 幀 |
| 命中火花 | 46px 放射光（白 → `#78cfff` → 透明），存活 120ms |
| 傷害數字 | 粗體白字＋`#35b9ff` 外光；爆擊 34px `#ffe08a`＋`#ff6a3d` 外光，結尾加「!」；往上飄 30px 後淡出 |
| 菁英死亡 | 畫面震動 4px／150ms，霓虹碎片 8–12 顆往外噴 |

同畫面發光物上限：子彈 60、寶石 80；超過就只畫實心不畫光暈。

## 5. HUD（割草模式）

- 最上方經驗條：整排寬、高 4px，底 `rgba(120,207,255,0.15)`，填 `#78cfff` 加外光。
- 左上面板：圓形頭像框（54px、2px `#78cfff` 框）＋名字＋LV（`#78cfff`）＋ HP 條（高 8px、`#f5a1bc` 加外光）＋武器格（26px 圓角框，已有武器框發光，空格虛線）。
- 正中計時：34px 粗體白字＋`#35b9ff` 外光。
- 右上：擊殺數（粉點）、寶石數（綠菱形）、暫停鈕（44px）。
- 右下特技鈕：84px 圓形，`#ffa94d` 框＋橘色外光，內部顯示充能。
- 觸控按鈕至少 44px。

## 6. Boss 單挑模式

- 場地：橢圓競技場（約畫面寬 53%、高 93%），3px `#78cfff` 邊框＋內外發光；內側再一圈 1px 淡青線。場外 `#120f24`。
- Boss 用黏土熊（240px），蓄力時身後一團橘色光暈。
- **弱點**：在 Boss 身上的弱點位置（讀現有 `render/weakpoint.js`）畫 24px 粉色發光核心＋48px 外圈，旁邊「弱點」小標籤（可設定只在前幾次挑戰顯示）。
- 預警：Boss 攻擊落點用第 4 節的預警圈，形狀跟著實際攻擊範圍。
- 命中弱點：時間放慢 0.3 秒、畫面震動、粉色霓虹碎片炸開。
- HUD 精簡：左上「一擊定勝負」（或現有生命顯示）、右上挑戰次數＋暫停、底部置中 Boss 名字 30px 粗體加橘色外光＋下方 2px 橘線。

## 7. 檔案與允許範圍

- 新增：`games/survivor/render/clay.js`（黏土角色設定＋預先繪製）、`games/survivor/render/neon.js`（光暈圖＋特效）。

- 禁止：`engine/**`、`data/**`、`stages.js`、`game.js` 的邏輯、任何數值。需要新的狀態資訊（例如「目前在蓄力第幾毫秒」）而現有資料沒有時，**停下來問家長**，不要自己改引擎。

## 9. 不要做的事

- 不要為了「更像黏土」引入 WebGL、3D 引擎或大型套件。
- 不要每幀用 `shadowBlur`／`filter`。
- 不要改玩法、數值、hitbox。
- 不要自己新增流程、審查關卡或規則；卡住同一原因兩次就停下問家長。
