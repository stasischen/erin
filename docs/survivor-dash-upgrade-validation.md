# 衝刺升級驗證

依據：`coord/inbox/done/20261025T162014Z-parent-dash-upgrade.md`。版本：`20261026c`。作者 Codex；尚待 Grok 獨立審查與 Erin 試玩。

## 試玩初值

- 衝刺預設兩格，每格依序回復 1.2 秒；正在衝刺時不重複扣格。按鈕仍為純像素圖示，外圈分段顯示格數及下一格回復進度。
- 衝刺全程免傷，保護初值 0.18 秒，並留下 0.22 秒淡殘影。Maker 可調保護時間；實際保護至少涵蓋整次衝刺。
- 衝刺結束後一秒內的第一次有效普攻（水球一輪齊射）傷害 1.8 倍、大小 1.5 倍，帶金色外圈及爆發。沒有目標不消耗強化；後續攻擊恢復正常。
- 在預測命中前 0.18 秒內衝刺，回 2 血（不超過上限），提供 0.35 秒保護、金色爆發與 0.3 秒的 35% 速度慢動作。支援逼近的投射物、接觸怪物、有預警的範圍傷害及粉筆牆／縮圈；同一威脅只獎勵一次，已有無敵時不再刷獎勵。老師衝撞與國字出手前的扇形預警不提供額外判定，發射後的國字依投射物判定。
- 老師新增 1.2 秒預警的粉筆牆與第二階段起的封閉縮圈；粉筆牆橫掃整個當時可見區域，縮圈收到中心，衝刺可穿過。原有留缺口罰站圈仍保留。移出老師視野仍遵循原有取消招式規則。
- Maker 提供格數、回復時間、無敵時間、完美閃避時間窗、回血／保護、慢動作及強化普攻數值。舊作品自動補新欄位及兩個新招式；一般遊戲保留已儲存的冷卻設定，可從設定頁恢復預設套用 1.2 秒。
- 水痕、旋風及閃電痕跡仍依每段移動留在世界座標，Lv1／Lv5 可用；「更快更遠」沿用現有疾風入門的水球速度／射程效果。衝刺欄卡片展示會演出衝刺及後續強化水球。

以上均為可調工程初值，未視為 Erin 已確認平衡。

## 執行結果

執行 `node games/survivor/tools/test.cjs --layout`：版本與 23 組非版面測試全部通過；唯一失敗為 `levelup-layout.cjs` 的真實 Chrome 啟動收到 `SIGABRT`，整體命令退出碼 1。沒有完成真實 Chrome 版面驗證，不以 VM 測試替代。

新增 `tests/dash-upgrade.cjs` 驗證依序充能、暫停／重開、無敵及殘影、強化普攻一次性／逾時、完美閃避命中時間／獎勵／慢動作／重複獎勵防護、接觸判定、老師兩招預警與衝刺免傷、跨地圖接縫粉筆牆移動、Maker 舊作品遷移／數值限制、衝刺卡 Lv1／Lv5。既有衝刺測試同步改為兩格及新冷卻。

153 組固定亂數玩法快照中，只有 3 組老師第三階段的第 39 幀變動：新增兩招使下一招的隨機選項改變（原粉筆→衝撞、原罰站圈→新縮圈、原考卷雨→點名），已同步快照；其餘 150 組結果相同。
