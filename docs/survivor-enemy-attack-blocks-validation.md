# 怪物與老師招式積木交接

本卡依家長同意的統一拼圖第 5 步實作；不新增招式、不調整平衡。版本 `20261026ae`。

## 資料與執行

武器、怪物與老師招式使用相同五類積木 `trigger / shape / timing / effect / feedback`，共享 `BLOCK_PARTS` 登錄、物件白名單檢查與 Maker 積木外殼。每個角色保留其合法參數與觸發方式；本次不讓怪物使用玩家按鍵或任意執行程式。

- 怪物的 `blocks.version: 1` 有兩個固定招式：`phase`（分階段攻擊）與 `legacy`（原等級／間隔攻擊）。`phase` 啟用時優先，未啟用才走原等級攻擊；原移動、護盾、衝撞等行為保留。
- 老師每個招式有一個 `move` 積木堆，涵蓋階段條件、形狀、預警／持續／連發時間與傷害。原三階段、合招、休息與安全圈不改。
- `SurvivorData.validate` 載入舊作品時產生積木；有積木時以積木為來源，編譯回原 `phaseAttack / attack` 與老師招式欄位。原引擎與繪圖接合層繼續處理傷害、預警、子彈上限與生命週期，不同時執行兩套攻擊。
- `phase` 的時機積木直接使用共用時間軸；老師和原等級攻擊保持其不同的既有計時語意，不額外加入起手／收招而改手感。
- 作品外層 `schemaVersion: 1` 與本機儲存 key 沿用；新增積木有獨立版本，拒絕未知版本、招式、欄位、觸發、回饋、缺值與超界值。舊作品無須手動轉檔。
- 與上一張武器卡一致，積木是載入後的編輯來源；直接改相容欄位會被積木編譯結果取代。舊的 `timing.cjs` 儲存案例已改為編輯積木，繼續驗證 1.7 秒的實際載入結果。

Maker 怪物與老師招式頁改為可收合的五類積木；武器也使用相同外殼。怪物旁保留獨立引擎的即時預覽與「試這隻」；老師旁保留單招即時展示，新增「試這隻」開啟單招展示。修改會更新目前草稿的預覽，不用先存檔。小螢幕仍以既有預覽開關收合。
