## 操作與範圍

從「自己設計」上方圓形播放圖示進入；左側保留 Maker 控制項，右側練習場左列為八個招式圖示。點招式、在畫面左半部拖曳跟隨搖桿，或讓練習場取得焦點後用方向鍵／WASD 移動。右上重播按鈕重設位置；外層關閉按鈕回完整 Maker。沿用遊戲外層的橫向旋轉，不新增第二個方向政策。

- 水球、棒棒糖錘（含每第四下旋轉）、浪花水球：真實普攻與命中引擎；兩個木頭假人可示範浪花互撞。假人受擊後回位，保留可見的推動。紅色時間軸表示普攻間隔；飛行與命中特效可能跨越下一次發射，沒有捏造預警或反擊窗。
- 布丁、蘑菇、仙子：直接使用 `updatePhasedAttack`、`SurvivorPacing.advanceAttack`、正式子彈／判定／預警繪圖；同一個 config 鎖定原點與方向。時間軸讀取實際階段與剩餘秒數。練習只播放攻擊，不混入仙子的護盾施放。
- 甜甜圈、跳跳糖：正式遊戲目前仍用 `e.action` 舊流程，因此直接呼叫該流程；時間軸明示「舊招式，無收招階段」，收招為零，甜甜圈冷卻沿用引擎 3 秒，跳跳糖自爆後短留畫面看特效再重播。未把這兩招改造成新的四階段玩法。練習預警以主角中心的碰撞區顯示：衝撞膠囊含雙方身體半徑，自爆圓含主角半徑。
- 無自然生成、升級、Boss、經驗掉落或結算；`damageDisabled` 保證免傷，沒有用無敵閃爍計時假裝免傷。
- Maker 滑桿輸入傳入目前有效 draft；只重載獨立練習 iframe，選中招式保留，未儲存的設定也可看。原因是現有引擎部分速度、傷害等以啟動時常數綁定，僅換物件會留下舊數值。驗證失敗時保留最後有效重播，錯誤由 Maker 狀態列顯示。
- 暫未加入可選的老師招式與連躲十次挑戰。

- §11.1：內容沿用目前作品資料，沒有另存攻擊數值副本。`practice-rules.js` 將目前資料轉成可序列化的招式模型；舊衝撞冷卻 3 秒仍來自現有引擎慣例，尚未集中進 JSON，之後應與舊招式遷移一起處理。
