# 跟隨左搖桿交接

來源：`coord/inbox/done/20261026T030704Z-parent-follow-joystick.md`。

## 行為與設定

- 左半畫面觸碰建立底座；超出半徑後沿拖曳方向跟隨，距手指保持一個半徑。底座碰界線就停止，方向與全速保持。
- 操作區是遊戲畫面左半部，底座內縮半徑加 19 單位，讓外圈及搖桿頭留在畫面內。邊緣初次觸碰的底座會移到此範圍內，按下當下仍是零輸入。極小視窗縮小繪圖。
- 放開、取消、失去 capture 時清掉該手指；其他指頭不能接管或終止移動。暫停、升級、重開、轉向沿用既有重置。
- Maker「數值」新增「左搖桿」：跟隨開關、半徑、死區。關閉跟隨時固定底座，仍保留死區及邊界。
- `data/defaults.js` 的 `joystick` 為可序列化資料：`follow` 布林，預設 true；`radius` 20～70，預設 35；`deadZone` 0～10，預設 4。距離使用經 `canvasPoint` 換算的遊戲畫面單位，並非裝置實體像素。
- 死區內零輸入；超出後線性增加，達半徑時全速。舊 Maker 作品缺少整個 joystick 區塊時補預設；無效數值與非布林開關拒絕載入，沿用既有驗證回退。
- 圓形、原有色彩與透明度沿用；資源及離線快取版本為 `20261026n`。
