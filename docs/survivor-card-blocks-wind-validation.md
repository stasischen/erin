# 風流派卡片積木交接

版本 `20261026ah`。作者 Codex；交 Grok 審查 erin-watch 提交的完整 SHA，沒有作者 approve。只搬移這十張風卡，保留原平衡、卡池、操作及舊作品的 feature/power 格式。

## 規則與接合

規則集中在 `engine/effect-blocks.js` recipes，以 `{ref:...}` 讀取 build、schoolRules 共用數值。事件輸入增加 moving（原 moveRate）；站定、風刃資格與範圍條件由純函式解讀。接合層仍負責合法目標、環繞座標、生命週期、傷害入口與畫面音效。

| 卡片 | 保留的行為 |
|---|---|
| wind-attack | 每級加快水球速度及飛行距離；近戰沿用原範圍倍率。 |
| wind-dash | 衝刺留下旋風；場地依原等級造成傷害及擊退；泡泡技能仍依原半徑倍率拉近怪物，沒有另加招式。 |
| wind-speed | 原 moveRate × 合併等級 × movingRate 決定攻速，沿用原最短間隔。 |
| wind-ultimate | 龍捲風依 elapsed、旋轉速度及環繞半徑移動；首次立即傷害，之後按 tornadoTick；嚴格小於場地半徑加目標半徑才命中。 |
| fusion-storm | 同時留下水、風兩種場地，沿用原生成順序、間距及上限；水傷等級仍取水技能／水衝刺／本卡最大值，風傷及範圍仍讀 wind-dash 等級，沒有改成合體卡等級。 |
| wind-blade | 遠程多穿一隻；仍可穿透且不是小風刃時，找第一個範圍內未命中目標，發出小風刃。近戰仍為範圍內一次追斬，不額外射水球。 |
| wind-gust | 等完整間隔後推開範圍內合法目標；邊界包含。 |
| wind-refund | 衝刺結束回充原比例的冷卻進度；歸零時最多補一格，半格進度不能當一格發動。 |
| wind-light | 移動及拾取分別使用原每級倍率；磁鐵顯示同步讀相同規則。 |
| wind-eye | 原 moveRate 大於 .01 時重設站定時間；等滿後推開嚴格範圍內怪物，推力乘 dt，攔下範圍內敵人子彈；風牆顯示半徑同步。 |

旋風保留先扣生命、到期移除、每次更新最多一跳，以及先傷害再推開的順序。所有卡仍經 effectLevel 合併 power 並封頂；不因多個來源重複掛載。水、雷規則本次沒有重新設計。
