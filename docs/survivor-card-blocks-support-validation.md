版本 `20261026ai`。作者 Codex；交 Grok 審查 erin-watch 提交的完整 SHA。這次只搬移九張支援卡，沒有改卡池、平衡或操作。

## 規則與相容性

`engine/effect-blocks.js` recipes 沿用原 feature id，以 `{ref:...}` 讀 tuning/build 共用數值。接合層保留目標選擇、環繞座標、傷害入口、生命週期與特效順序；公式與回血條件由純規則解讀。新增 ceil/divide/power 運算保留護盾取整與回血等級間隔。

| 卡片 | 保留行為 |
|---|---|
| big-water | 遠近程普攻大小與傷害各自乘原每級倍率。 |
| rapid-water | 原武器間隔乘每級減幅，再除移動攻速，最後保留 0.12 秒下限。 |
| multi-water | 遠程發射 1＋等級顆、中心對稱散射；近戰增加原角度。 |
| onion-dash | 原走路速度乘每級倍率，保留衝刺、場外減速及糖漿影響。 |
| bubble-shield | 每級增加 ceil(基本血量／護盾除數) 上限；選卡時只補一次原固定量，不按 power 倍增，保留王冠與血量下限。 |
| gem-magnet | 原拾取範圍乘每級倍率；與風卡及中立磁鐵相乘，磁鐵顯示同步。 |
| piercing-water | 遠程增加等級次穿透；近戰保留每級 0.1 的固定範圍係數。 |
| splash-water | 嚴格小於基本半徑＋每級半徑；原傷害比例。遠程仍只濺附近可攻擊小怪並加入 hitList；近戰仍用 combatTargets 排除本次揮擊命中者。不新增對老師的遠程水花。 |
| auto-heal | 原間隔乘每級指數倍率；累積計時、長 dt 補足多跳，滿血仍消耗計時；缺血才補 1 並限制上限。 |

共用數值仍寫回原作品欄位；舊 feature/power、合併封頂與儲存格式不變。九卡在 Maker「技能卡」顯示可收合積木、中文觸發／條件／動作、共用數值與整卡／單效果預覽。原本寫死的穿透近戰係數 0.1、每跳回血 1 等固定規則常數保留，沒有新增平衡設定。遊戲、練習場、預覽 URL 與 Service Worker 快取一起升版。
