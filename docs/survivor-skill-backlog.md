## 英雄聯盟（LoL）靈感

- ⭐ 疊層被動：累積攻擊次數，每第 3 下攻擊變強。（靈感：LoL）
- ⭐ 標記引爆：先替敵人加標記，達成條件後一次引爆。（靈感：LoL）
- 斬殺低血怪：敵人血量低於條件時，攻擊可直接收尾。（靈感：LoL）
- ⭐ 擊殺重置冷卻：打倒敵人後重置指定能力的冷卻。（靈感：LoL）
- ⭐ 迴力鏢：投射物飛出去與飛回來都能打中敵人。（靈感：LoL）
- 主動護盾：按技能後暫時吸收傷害；與現有「泡泡護盾」增加最大血量不同。（靈感：LoL）
- 吸血：依造成的傷害回復部分血量；與現有定時自動補血不同。（靈感：LoL）
- 變身大招：短時間變身並改變攻擊方式。（靈感：LoL）
- 造牆擋怪：製造暫時阻擋敵人移動的牆。（靈感：LoL）
- 分身：產生模仿主角的分身；與現有原地自動射擊小幫手不同。（靈感：LoL）
- 一場一次復活：每場第一次倒下時復活。（靈感：LoL）
- 蓄力：站著不動累積力量，讓下一擊變強。（靈感：LoL）

## 未來武器方向（備忘，不實作）

來源：[家長的武器備忘收件匣](../coord/inbox/done/20261025T142630Z-parent-weapon-backlog.md)。以下依家長提供的黑帝斯（Hades）與 Brotato 靈感整理成提案，不是原作規則的完整介紹，也不表示已決定製作。維持全自動攻擊，不用手動瞄準或換彈；武器名稱、數值、解鎖方式與製作順序仍由 Erin 和家長決定。

### 1. 每把武器有不同手感

| 武器提案 | 自動攻擊方式與手感 |
|---|---|
| 水槍 | 朝最近的怪打出直線水柱，輸出穩定，適合新手。 |
| 紙飛機 | 像迴力鏢飛出去再飛回來，去程與回程都能打到怪。 |
| 彈弓 | 射出慢速子彈，在怪之間彈跳。 |
| 泡泡棒 | 主角周圍一圈泡泡，怪越近，傷害越高。 |
| 掃把（近戰） | 自動朝短距離內最近的怪揮出一道弧形；傷害高，可搭配擊退或小護盾，讓近身攻擊對小朋友更友善。 |

依收件匣提供的 Brotato 式近戰分類，可借鏡「刺擊」（朝前直線刺出）和「橫掃」（揮出弧形）兩種手感；掃把提案採橫掃。它可以搭配現有卡片概念：跳電＝命中時連鎖電到附近的怪；水窪＝沿著揮動軌跡留下水痕。這些是未來的武器搭配效果，尚未實作。

紙飛機延續上面的「迴力鏢」技能點子；掃把的擊退與跳電可沿用既有積木方向，小護盾的具體效果仍待設計。這裡整理的是新武器手感，不把既有擊退、連鎖或衝刺水痕再算成新機制。

### 2. 同一張卡，配不同武器有不同效果

借鏡黑帝斯的祝福搭配方向：同一張卡保留主題，依武器改變觸發時機或表現。例如「跳電」裝在水槍上，是命中時連鎖到附近的怪；裝在紙飛機上，則是飛回來時放電。掃把版本可用上面的命中連鎖提案。

未來卡面與預覽需讓玩家看得懂這把武器會得到什麼效果；各搭配的傷害、範圍和觸發限制另待決定，不視為現有卡片已支援這些武器差異。

### 3. 武器變體

借鏡黑帝斯的 aspect：日後每把武器可有一兩種變體，例如「三連發水槍」或「又大又慢的水球」，改變攻擊節奏與手感。可以做成解鎖內容，或讓玩家在 Maker 裡設計；採哪種方式、條件與效果，等 Erin 和家長決定。

### 4. 平衡原則與取捨

「近戰強，遠距就弱；遠距強，近戰就弱」是可挑選的取捨方向，不必每把武器都用同一個限制。以下依收件匣保留其他可比較的方向，尚未指定數值或套用到任何武器／卡片。

| 取捨 | 設計時比較什麼 |
|---|---|
| 近戰 vs 遠程 | 貼近時傷害高，或從遠處攻擊比較安全。 |
| 單體 vs 範圍 | 集中打倒一隻，或同時打到一群。 |
| 攻速 vs 單發 | 打得快但每下較輕，或打得慢但每下較重。 |
| 攻擊 vs 生存 | 借鏡 Brotato 式「+X −Y」道具，例如加傷害、減血量；代價要清楚可見。 |
| 移速 vs 火力 | 跑得更快，或攻擊更強。 |
| 穩定 vs 爆發 | 持續穩定輸出，或等一段時間集中打出高傷害。 |
| 立即 vs 成長 | 現在就變強，或透過永久疊加逐步變強；疊加是否跨場保留，另待決定。 |
| 安全 vs 冒險 | 安全走位，或越靠近怪／血越少時傷害越高。 |
| 專精 vs 混搭 | 集中同一路線取得終極卡，或組合不同路線取得合體卡。 |

適合小朋友的規則：**每張卡最多只有一個明顯、看得到的缺點**，讓選擇容易理解。哪些取捨好玩、近戰需要多少擊退或保護，留待日後設計與試玩確認。

收件匣的建議順序是：先做每場只隨機開放 2 條升級線，再做手感差很多的水槍與紙飛機，之後增加更多武器，最後才加 Brotato 式角色被動。這延續上面的「黑帝斯式迷你版」備註；目前只記錄建議，不排定開工，也不新增實作卡。是否採用、先做哪項，由 Erin 和家長日後決定。

## 聚氣機制（備忘，不實作）

來源：[家長的聚氣備忘收件匣](../coord/inbox/done/20261025T143015Z-parent-charge-backlog.md)。自動普攻也能透過站定、時間或命中等條件聚氣，不必增加普攻按鈕；衝刺與技能則可考慮按住後放開。以下七項都是未來提案，維持普攻自動、不用手動瞄準或換彈的方向；⭐ 沿用收件匣推薦，不代表已決定製作或排定順序。

- ⭐ 站著不動就聚氣：站著 1～2 秒，下一發自動攻擊變成大顆蓄力彈；與上面 LoL「蓄力」是同一方向，可搭配彈弓站著丟大石頭的提案（前節彈弓的彈跳子彈是另一種手感），也和現有風流派「移動越快，水球發射越快」形成取捨。
- 時間自動蓄滿：每 N 秒或每第 5 發自動變強，不用額外操作、適合小朋友；按攻擊次數觸發與上面 LoL「疊層被動」重疊，定時部分與現有間隔觸發積木有關，但蓄滿後強化下一擊仍是待設計機制。
- 命中累積：命中或連續擊殺累積氣條，滿了下一擊變強；與上面 Hades「憤怒條」同屬累積能量的方向，但獎勵是強化下一擊，也與 LoL「疊層被動」部分重疊，擊殺給氣則不同於「擊殺重置冷卻」。
- 閃避給氣：抓準時機的完美衝刺累積一格氣；是上面 Hades「完美閃避」的獎勵提案，也可作為「憤怒條」的能量來源，現有衝刺無敵尚無完美時機判定與給氣獎勵。
- 撿能量球給氣：撿到能量球累積氣條；可作為上面 Hades「憤怒條」的另一種能量來源，與現有撿經驗寶石升級不同，能量球和聚氣用途尚未實作。
- 按住衝刺：按越久，放開時衝得越遠、越強；與 LoL「蓄力」共用按時間累積力量的概念，但用於衝刺，與現有按下即衝刺不同，也不等同「完美閃避」的時機獎勵。
- 按住技能：按越久，放開時範圍越大；與 LoL「蓄力」共用蓄力概念，但用於主動技能，與現有按下即施放不同，也不等同「憤怒條」累滿後施放超大招。

以上只記錄，不新增聚氣條、能量球或按住操作，也不修改現有普攻、衝刺、技能與 Maker。1～2 秒、第 5 發與 N 秒都是提案示例；是否採用、蓄力時是否持續普攻、移動會否中斷、上限與獎勵數值、觸控手感及製作順序，等 Erin 和家長日後決定再開實作卡。

核對依據：[老師招式資料](../games/survivor/data/defaults.js)、[老師攻擊](../games/survivor/engine/boss.js)、[小兵攻擊](../games/survivor/engine/spawn.js)與 [Maker 積木格式](../games/survivor/data/schema.js)。Maker 的卡片積木主要作用於玩家攻擊敵人，不能直接視為敵人也能對玩家施加同樣效果；敵人攻擊積木目前提供投射物、預警範圍傷害與召喚。

### 射擊

- 直線射擊：瞄準方向後直線射出，先顯示發射方向；現有小兵丟字與老師國字／粉筆已涵蓋直線投射物，Maker 敵人投射物積木可沿用，新增預警方式另待設計。
