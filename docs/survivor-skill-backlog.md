# 未來可以加的技能（備忘，不實作）

來源：[家長的技能備忘收件匣](../coord/inbox/done/20261025T141520Z-parent-skill-backlog.md)。以下依原紀錄整理靈感遊戲與 ⭐ 推薦標記；遊戲名稱是靈感分類，不表示逐項照搬原作規則。⭐ 也不表示已決定製作或排定順序，是否開卡、名稱、數值和玩法由 Erin 與家長決定。

這次只寫文件。未來新增技能建議做成 Maker 的效果積木，讓不同卡片能共用和組合；涉及商店、視野或角色選擇的點子另需流程設計。維持自動攻擊、只操作走位＋衝刺＋技能的現有方向。

## 英雄聯盟（LoL）靈感

- ⭐ 疊層被動：累積攻擊次數，每第 3 下攻擊變強。（靈感：LoL）
- ⭐ 標記引爆：先替敵人加標記，達成條件後一次引爆。（靈感：LoL）
- 斬殺低血怪：敵人血量低於條件時，攻擊可直接收尾。（靈感：LoL）
- ⭐ 擊殺重置冷卻：打倒敵人後重置指定能力的冷卻。（靈感：LoL）
- ⭐ 迴力鏢：投射物飛出去與飛回來都能打中敵人。（靈感：LoL）
- 主動護盾：按技能後暫時吸收傷害；與現有「泡泡護盾」增加最大血量不同。（靈感：LoL）
- 吸血：依造成的傷害回復部分血量；與現有定時自動補血不同。（靈感：LoL）
- 變身大招：短時間變身並改變攻擊方式。（靈感：LoL）
- 造牆擋怪：製造暫時阻擋敵人移動的牆。（靈感：LoL）
- 分身：產生模仿主角的分身；與現有原地自動射擊小幫手不同。（靈感：LoL）
- 一場一次復活：每場第一次倒下時復活。（靈感：LoL）
- 蓄力：站著不動累積力量，讓下一擊變強。（靈感：LoL）

## 黑帝斯（Hades）靈感

- ⭐ 狀態疊加：讓脆弱（受到更多傷害）或中毒（持續扣血）累積層數。（靈感：Hades）
- 反彈怪的子彈：把敵方投射物反彈回去；與現有受傷放電反擊不同。（靈感：Hades）
- ⭐ 完美閃避：在即將被打中的瞬間衝刺，成功躲開後獲得獎勵；現有衝刺無敵尚無此判定與獎勵。（靈感：Hades）
- ⭐ 憤怒條 → 超大招：累積能量後施放超大招；與現有定時發動的終極卡不同。（靈感：Hades）
- 關卡間商店與錢幣：打完一段後用錢幣買東西；延續計畫 §8 的商店點子，目前仍未實作。（靈感：Hades）
- 詛咒卡／挑戰誓約：主動選擇更難的條件，換取更多獎勵。（靈感：Hades）
- 鍛造升級：把卡變稀有或改變效果方向；與現有卡片升級、前置解鎖及合體卡不同。（靈感：Hades）
- 混沌門：先承受暫時缺點，之後換來更大的好處。（靈感：Hades）

## 20 Minutes Till Dawn 靈感

- 彈匣式特殊武器：只有未來另行選用時才考慮彈匣與換彈；家長不喜歡換彈，現有不換彈方向不變。（靈感：20 Minutes Till Dawn）
- ⭐ 子彈分裂：子彈命中或達成條件後分成多顆；與現有同時多發、穿透及濺射不同。（靈感：20 Minutes Till Dawn）
- ⭐ 死亡時狀態蔓延：帶有狀態的敵人被打倒後，把狀態傳給附近敵人。（靈感：20 Minutes Till Dawn）
- 召喚物升級線：讓召喚物逐步取得新行為；現有小幫手和卡片前置可作基礎，不重列單純召喚或提高傷害。（靈感：20 Minutes Till Dawn）
- 黑暗視野與照明卡：縮小可見範圍，讓照明卡擴大視野。（靈感：20 Minutes Till Dawn）
- ⭐ 角色天生被動：每個角色開場就有不同能力；延續計畫 §9 的角色特色，效果由 Erin 設計。（靈感：20 Minutes Till Dawn）
