## 英雄聯盟（LoL）靈感

- ⭐ 疊層被動：累積攻擊次數，每第 3 下攻擊變強。（靈感：LoL）
- ⭐ 標記引爆：先替敵人加標記，達成條件後一次引爆。（靈感：LoL）
- 斬殺低血怪：敵人血量低於條件時，攻擊可直接收尾。（靈感：LoL）
- ⭐ 擊殺重置冷卻：打倒敵人後重置指定能力的冷卻。（靈感：LoL）
- ⭐ 迴力鏢：投射物飛出去與飛回來都能打中敵人。（靈感：LoL）
- 主動護盾：按技能後暫時吸收傷害；與現有「泡泡護盾」增加最大血量不同。（靈感：LoL）
- 吸血：依造成的傷害回復部分血量；與現有定時自動補血不同。（靈感：LoL）
- 變身大招：短時間變身並改變攻擊方式。（靈感：LoL）
- 造牆擋怪：製造暫時阻擋敵人移動的牆。（靈感：LoL）
- 分身：產生模仿主角的分身；與現有原地自動射擊小幫手不同。（靈感：LoL）

## 未來武器方向（備忘，不實作）

來源：[家長的武器備忘收件匣](../coord/inbox/done/20261025T142630Z-parent-weapon-backlog.md)。以下依家長提供的黑帝斯（Hades）與 Brotato 靈感整理成提案，不是原作規則的完整介紹，也不表示已決定製作。維持全自動攻擊，不用手動瞄準或換彈；武器名稱、數值、解鎖方式與製作順序仍由 Erin 和家長決定。

### 1. 每把武器有不同手感

| 武器提案 | 自動攻擊方式與手感 |
|---|---|
| 水槍 | 朝最近的怪打出直線水柱，輸出穩定，適合新手。 |
| 紙飛機 | 像迴力鏢飛出去再飛回來，去程與回程都能打到怪。 |
| 彈弓 | 射出慢速子彈，在怪之間彈跳。 |
| 泡泡棒 | 主角周圍一圈泡泡，怪越近，傷害越高。 |
| 掃把（近戰） | 自動朝短距離內最近的怪揮出一道弧形；傷害高，可搭配擊退或小護盾，讓近身攻擊對小朋友更友善。 |

依收件匣提供的 Brotato 式近戰分類，可借鏡「刺擊」（朝前直線刺出）和「橫掃」（揮出弧形）兩種手感；掃把提案採橫掃。它可以搭配現有卡片概念：跳電＝命中時連鎖電到附近的怪；水窪＝沿著揮動軌跡留下水痕。這些是未來的武器搭配效果，尚未實作。

紙飛機延續上面的「迴力鏢」技能點子；掃把的擊退與跳電可沿用既有積木方向，小護盾的具體效果仍待設計。這裡整理的是新武器手感，不把既有擊退、連鎖或衝刺水痕再算成新機制。

### 2. 同一張卡，配不同武器有不同效果

借鏡黑帝斯的祝福搭配方向：同一張卡保留主題，依武器改變觸發時機或表現。例如「跳電」裝在水槍上，是命中時連鎖到附近的怪；裝在紙飛機上，則是飛回來時放電。掃把版本可用上面的命中連鎖提案。

未來卡面與預覽需讓玩家看得懂這把武器會得到什麼效果；各搭配的傷害、範圍和觸發限制另待決定，不視為現有卡片已支援這些武器差異。

### 3. 武器變體

借鏡黑帝斯的 aspect：日後每把武器可有一兩種變體，例如「三連發水槍」或「又大又慢的水球」，改變攻擊節奏與手感。可以做成解鎖內容，或讓玩家在 Maker 裡設計；採哪種方式、條件與效果，等 Erin 和家長決定。

### 4. 平衡原則與取捨

「近戰強，遠距就弱；遠距強，近戰就弱」是可挑選的取捨方向，不必每把武器都用同一個限制。以下依收件匣保留其他可比較的方向，尚未指定數值或套用到任何武器／卡片。

| 取捨 | 設計時比較什麼 |
|---|---|
| 近戰 vs 遠程 | 貼近時傷害高，或從遠處攻擊比較安全。 |
| 單體 vs 範圍 | 集中打倒一隻，或同時打到一群。 |
| 攻速 vs 單發 | 打得快但每下較輕，或打得慢但每下較重。 |
| 攻擊 vs 生存 | 借鏡 Brotato 式「+X −Y」道具，例如加傷害、減血量；代價要清楚可見。 |
| 移速 vs 火力 | 跑得更快，或攻擊更強。 |
| 穩定 vs 爆發 | 持續穩定輸出，或等一段時間集中打出高傷害。 |
| 立即 vs 成長 | 現在就變強，或透過永久疊加逐步變強；疊加是否跨場保留，另待決定。 |
| 安全 vs 冒險 | 安全走位，或越靠近怪／血越少時傷害越高。 |
| 專精 vs 混搭 | 集中同一路線取得終極卡，或組合不同路線取得合體卡。 |

適合小朋友的規則：**每張卡最多只有一個明顯、看得到的缺點**，讓選擇容易理解。哪些取捨好玩、近戰需要多少擊退或保護，留待日後設計與試玩確認。

收件匣的建議順序是：先做每場只隨機開放 2 條升級線，再做手感差很多的水槍與紙飛機，之後增加更多武器，最後才加 Brotato 式角色被動。這延續上面的「黑帝斯式迷你版」備註；目前只記錄建議，不排定開工，也不新增實作卡。是否採用、先做哪項，由 Erin 和家長日後決定。

## 聚氣機制（備忘，不實作）

來源：[家長的聚氣備忘收件匣](../coord/inbox/done/20261025T143015Z-parent-charge-backlog.md)。自動普攻也能透過站定、時間或命中等條件聚氣，不必增加普攻按鈕；衝刺與技能則可考慮按住後放開。以下七項都是未來提案，維持普攻自動、不用手動瞄準或換彈的方向；⭐ 沿用收件匣推薦，不代表已決定製作或排定順序。

- ⭐ 站著不動就聚氣：站著 1～2 秒，下一發自動攻擊變成大顆蓄力彈；與上面 LoL「蓄力」是同一方向，可搭配彈弓站著丟大石頭的提案（前節彈弓的彈跳子彈是另一種手感），也和現有風流派「移動越快，水球發射越快」形成取捨。
- 時間自動蓄滿：每 N 秒或每第 5 發自動變強，不用額外操作、適合小朋友；按攻擊次數觸發與上面 LoL「疊層被動」重疊，定時部分與現有間隔觸發積木有關，但蓄滿後強化下一擊仍是待設計機制。
- 命中累積：命中或連續擊殺累積氣條，滿了下一擊變強；與上面 Hades「憤怒條」同屬累積能量的方向，但獎勵是強化下一擊，也與 LoL「疊層被動」部分重疊，擊殺給氣則不同於「擊殺重置冷卻」。
- 閃避給氣：抓準時機的完美衝刺累積一格氣；是上面 Hades「完美閃避」的獎勵提案，也可作為「憤怒條」的能量來源，現有衝刺無敵尚無完美時機判定與給氣獎勵。
- 撿能量球給氣：撿到能量球累積氣條；可作為上面 Hades「憤怒條」的另一種能量來源，與現有撿經驗寶石升級不同，能量球和聚氣用途尚未實作。
- 按住衝刺：按越久，放開時衝得越遠、越強；與 LoL「蓄力」共用按時間累積力量的概念，但用於衝刺，與現有按下即衝刺不同，也不等同「完美閃避」的時機獎勵。
- 按住技能：按越久，放開時範圍越大；與 LoL「蓄力」共用蓄力概念，但用於主動技能，與現有按下即施放不同，也不等同「憤怒條」累滿後施放超大招。

以上只記錄，不新增聚氣條、能量球或按住操作，也不修改現有普攻、衝刺、技能與 Maker。1～2 秒、第 5 發與 N 秒都是提案示例；是否採用、蓄力時是否持續普攻、移動會否中斷、上限與獎勵數值、觸控手感及製作順序，等 Erin 和家長日後決定再開實作卡。

### 資料驅動的連攜架構

- 連攜是一筆筆獨立資料，描述「需要的標籤或卡片 → 效果」。
- 由獨立的連攜管理器監聽選卡事件並檢查條件；卡片本身不知道有哪些連攜。
- 效果透過 hook（效果掛接點）掛上或卸下。
- 條件用標籤判斷，不寫死卡片名稱；若需指定卡片，資料如何識別另待設計。
- 多個視覺效果互相衝突時，用優先順序決定呈現哪個；排序規則尚待決定。

這是沿用我們 JS 資料驅動方向的架構備忘，不新增資料格式、管理器或 hook，也不把現有 Maker 積木視為已具備完整連攜系統。

### 目前狀況與造型基礎

依本次收件匣描述，目前一般小怪只有小熊軟糖和蒲公英兩種，都是追著主角跑、偶爾射一發；約 120 秒的關卡主要調整兩種怪的比例和生成速度。已有 **13 種甜點森林 sprite** 可供選用，並非已經有 13 種不同的小怪行為；造型與行為分開看，沿用[既有怪物造型](survivor-cute-monsters-validation.md)作為下列八種行為的外觀。

### 八種行為

| 類型 | 造型 | 規劃行為與用途 |
|---|---|---|
| 追趕型 | 小熊軟糖 | 數量最多，追著主角跑，是用來打的沙包怪；全程都保留。 |
| 快速型 | 蒲公英 | 速度快、血少，用弧線接近主角。 |
| 坦克型 | 布丁 | 慢、很耐打，會擋住其他怪。 |
| 射手型 | 蘑菇 | 保持距離，先閃一下再射擊，然後後退。 |
| 衝撞型 | 甜甜圈 | 先停下來抖一抖，再直線衝過來。 |
| 自爆型 | 跳跳糖 | 紅色閃爍 **2 秒**後爆炸，爆炸也會傷到怪物。 |
| 分裂型 | 果凍 | 死掉時分裂成 **2 隻**。 |
| 輔助型 | 棉花糖仙子 | 躲在後面，替附近的怪加護盾，是優先要打的目標。 |

這些延續前節「未來可以加的敵人」的衝鋒、自爆、分裂、遠程和護盾等方向，現在補上造型與節奏；不將換造型或已有的射擊能力算成全新機制，也不表示這八種行為已完成。

## 魂系風格靈感（備忘，不實作）

來源：[家長的魂系與 Rubinite 備忘收件匣](../coord/inbox/done/20261026T015427Z-parent-soulslike-backlog.md)。以下依原紀錄保留點子與 ⭐ 建議先做的標記；只記錄，不改遊戲、不新增實作卡，也不更動[深度路線圖已確認的製作順序](survivor-game-plan.md#123-已決定的製作順序)。是否採用、名稱、細節與開工順序仍由 Erin 和家長決定。靈感分類不是原作規則的完整介紹。

現況核對依據：[戰鬥與完美閃避](../games/survivor/engine/combat.js)、[衝刺恢復與回血](../games/survivor/engine/loop.js)、[Boss 招式與轉階段](../games/survivor/engine/boss.js)、[巧克力大熊與獎勵](../games/survivor/engine/encounters.js)及[預設資料](../games/survivor/data/defaults.js)。**本節以目前程式為準：完美閃避已有時機判定、回血、短暫保護與慢動作獎勵**；前面較早的 Hades／聚氣備忘中「尚無判定與獎勵」是當時的紀錄，不代表目前狀態。

### 七個魂系點子

1. ⭐ **看得懂的 Boss 招式**：有清楚的起手動作，節奏固定、可以學會，例如大熊舉起手臂就是要重擊地面。建立在現有預警和完美閃避上；大熊已有預警重擊，老師也已有招式預警與休息節奏，這裡擴充的是可辨識的起手動作與可學習節奏，不重做既有閃避系統。
2. **衝刺消耗體力**：一直狂按衝刺會用光；只保留為可以開關的挑戰模式。現有衝刺使用次數與冷卻恢復，並非體力條；與 Hades「挑戰誓約」的自選難度方向重疊，不直接替換目前操作。
3. ⭐ **死掉後撿回糖果**：死掉時糖果留在原地，下一場可以去撿回來，像撿回靈魂。現有撿經驗寶石是當場升級，並不是跨場回收；「糖果」代表什麼、保留多少、跨關位置如何對應，以及再次死亡如何處理，留待設計，不自行決定損失規則。
4. **餅乾營火存檔點**：關卡中途回血並選一張卡，但小怪會重新出現。回血與選卡可參考現有機制；中途存檔、休息後重新出怪則是新流程，與既有換關保留本局成長不同，也與先前特殊房間的方向部分重疊。
5. **限次糖漿回血**：每場只有 **3 次**，喝的時候停下 **1 秒**；只保留為可以開關的挑戰模式。現有自動補血與完美閃避回血不是限次喝藥；如何與這些回血並用或取代，待 Erin 和家長決定。此處糖漿是回血提案，並非現有敵人留下的緩速糖漿。
6. ⭐ **Boss 半血第二階段**：血量剩一半時換新招式，例如大熊融化成巧克力瀑布。老師已有約 **66%／33%** 血量的階段轉換與後期招式，故轉階段不是全新機制；半血門檻、大熊變形與巧克力瀑布仍是提案，不把現有老師門檻改成半血。
7. **怪物圖鑑的小故事**：在怪物圖鑑裡加小小的背景故事。延續深度路線圖的「解鎖和收藏圖鑑」，是內容擴充方向，不表示圖鑑已完成；故事由 Erin 設計。

### 紅眼露比 Rubinite 靈感

1. ⭐ **紅眼專注**：站著盯住敵人會累積印記，最多 **3 個**，離越近累積越快；被打到會清掉所有還沒用的印記，用掉印記可以放出強力的特殊攻擊。與 LoL「蓄力／標記引爆」、聚氣的「站著不動」及武器取捨的「安全 vs 冒險」部分重疊；專注對象、三格印記與受擊清空仍待設計，維持自動瞄準的方向。
2. ⭐ **專注時完美閃避加印記**：專注時成功完美閃避會多一個印記，獎勵冒險貼近的打法。延伸現有完美閃避與前面的「閃避給氣」備忘；增加印記是新獎勵，不表示現有回血等獎勵已被取代。
3. **公平的 Boss**：有清楚的起手動作、固定節奏，每一招都有破解方法，多個 Boss 輪流上場。起手與節奏和魂系點子 1 重疊；多 Boss 延續深度路線圖的小頭目／Boss 擴充目標，輪替方式未決定，不直接改成現有每關隨機的規則。
4. **靈活主角、沒有體力條**：難度來自 Boss，而不是笨重操作。與魂系點子 2 的體力條衝突，因此體力只保留為可開關的挑戰模式；本卡不加入體力或調整主角手感。
5. **換階段掉落水晶**：Boss 換階段時掉水晶，可升級天賦或護符，就算輸了也會成長。現有轉階段和打倒大熊後選卡可作參考，但轉階段掉落、天賦／護符與跨場成長尚未實作；與解鎖收藏的長期成長方向部分重疊，不自行決定永久保存方式。
6. **兩輪挑戰**：第一輪是教學；第二輪隱藏 Boss 血條，而且被打到就會一擊死。和挑戰誓約同屬難度提案；這是兩輪流程，不等同目前的兩個關卡。本卡不啟用隱藏血條或一擊死，是否採用與進入方式留待 Erin 和家長決定。

### 建議改編：甜甜能量

把 Rubinite 點子 **1＋2** 改編為「甜甜能量」條：**站著不動或靠近敵人時累積，被打到就歸零，充滿時放出終極技**，可以配合完美閃避和自動瞄準。這是紅眼專注的另一種改編提案，不直接把「最多 3 個印記」等同能量條數值；完美閃避如何給能量、是否自動施放或按技能，以及與現有技能的關係，都未定案。

這與 Hades「憤怒條 → 超大招」、聚氣的站定／閃避給氣，以及 LoL「蓄力」重疊，可合併考慮；現有自動瞄準與完美閃避可作基礎，但能量條、受擊歸零與累滿終極技尚未實作。站定或貼近的判定、累積速度、能量上限、終極技效果、糖果回收與跨場成長規則，等日後選定實作項目再決定，不在這張備忘卡代填。
