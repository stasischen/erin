# 打擊手感與敵人預警交接

版本：20261026x。來源：`coord/inbox/done/20261026T070053Z-parent-hit-juice-telegraph.md`。

## 實作與工程初值

- 近戰用沿揮擊方向、快速淡出的新月刀光；突刺用尖細光跡。正式遊戲不畫近戰判定扇形／矩形。傷害、碰撞、推退與連段倍率仍取既有規則。
- 每個實際扣血的近戰命中產生一次表現：一個 render 的白色剪影、壓扁 0.14 秒、接觸點火花；同一揮擊多目標的頓幀取最大值，不相加。普通頓幀 0.05 秒、震動 2 世界單位；終結段／蓄力／衝刺突刺為 1.5 倍，刀光加粗。後退沿用原有重量與擊退系統。
- Maker「怪物」增加打擊回饋開關與 0–2 強度拉桿；0 等同關閉新增的頓幀、震動、火花與壓扁。一般遊戲的畫面震動設定仍優先控制震動。舊作品自動補 enabled=true、intensity=1，驗證與存檔保留設定。
- 分階段敵人蓄力時壓扁、變紅並抖動，頭上用像素驚嘆號；地面範圍按該次 config.windup 秒數向外填滿，生效時完整著色、身體閃白，收招灰色加星星。投射招式地面為各發方向的細長路徑，出招後以真實子彈顯示危險，避免將整段路徑誤畫成同時生效。
- 分階段命中仍只在 active；不替舊衝撞／自爆／一般射擊捏造不存在的 recovery。舊招式沿用自身地面警示，身體也增加蓄力動作；既有身體傷害開關仍有效。收招安全提示指該次招式，其他子彈仍需躲避。
- 四色時間軸只在練習場。練習場選單增加預設關閉的「顯示判定框」，可顯示近戰完整範圍、分階段完整地面範圍、投射預警加主角半徑與舊衝撞／自爆範圍；正式遊戲無此除錯開關。
- 練習敵人在待機／冷卻時追近主角，保留施招時站定與衝撞移動；每輪不再搬回固定點，離遠會追近再開下一輪。「試這隻」和選單使用同一引擎；木樁持續追擊，保留擊退與武器連段。Maker 設為速度 0 的敵人仍尊重該設定。
- 頓幀用真實 dt 倒數並凍結模擬時間；暫停不倒數，重開清零。震動使用獨立表現時鐘，凍結時仍能晃動。像素染色剪影快取、火花沿用 90 個粒子上限與物件池，無新增外部素材／音訊。

## 驗證與獨立審查

Codex 只執行 `node games/survivor/tools/test.cjs`，最後一輪全部通過；沒有執行 `--layout` 或瀏覽器操作。自動案例新增：命中扣血後的頓幀、暫停與重設、單 render 閃白、強化攻擊、關閉／零強度、粒子上限、舊作品遷移／非法資料、Maker 開關與拉桿存檔重開、所有敵人的練習追擊與不瞬移，以及不同 windup 秒數對應地面填滿半徑。既有攻速案例加入頓幀後仍維持 0.7 秒模擬時間攻擊間隔。

請 Grok 獨立審查最後實質 SHA，並在 1024×461、740×360 實際操作：

1. 大劍左右揮、第三段、聚氣重擊與錘子旋轉；確認刀光淡出、接觸點火花、白閃、壓扁與推退清楚。
2. Maker 關閉／0／1／2 強度，及遊戲震動開關；試多目標，觀察手機效能與頓幀是否合適。
3. 布丁／蘑菇／仙子調短、調長 windup；確認填滿時機、生效才受傷、收招反擊；子彈仍在飛時繼續躲避。
4. 練習場每個招式與敵人「試這隻」，走遠、追近、重播、暫停、連續出招；切判定框開關，確認正式遊戲無框。
5. 兩項待辦只記錄於技能備忘，未改突刺平衡與分頁版面。手感是否適合仍由 Erin 試玩決定，未核准上線。
