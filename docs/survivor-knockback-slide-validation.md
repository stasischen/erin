# 擊退滑動交接

來源：`coord/inbox/done/20261026T134658Z-parent-knockback-slide.md`；版本 `20261026at`。

## 行為

- `shiftTarget` 保留共用積木接合入口，改為加入衝量，不直接改座標。普攻、武器重擊、school shot.push、風流派、Maker、炸彈、中立浪花和老師跳躍推主角共用 `SurvivorSlide`。
- 預設 0.2 秒二次 ease-out：初速為 `2 × 距離 / 秒數`，速度線性降到零。以固定 1/120 秒物理步長精確積分，每步掃掠；不足一步的時間保存在 `pending`，非整步持續時間的最後一小步依剩餘秒數積分。不同渲染幀率保留同樣總距離；頓幀與暫停期間不推進。
- 單次無阻擋推拉保留原距離及重量倍率。舊普攻 90 單位／秒逐秒減少的理想總距離為 45，新普攻沿用 45；炸彈仍只用炸彈的距離，不另外疊加普攻。老師預設推拉倍率仍為 0，小頭目沿用重量 8。
- 依家長補充（`coord/inbox/done/20261026T142627Z-parent-knockback-slide-rules.md`），被推動的主角、小怪、小頭目、精英與可推動的老師暫時失控：不能自主移動、普攻、手動出招、放技能或開始衝刺；小怪行為、小頭目出招／精英瞬移與老師招式暫停，最後一步所在幀仍保持失控，下一幀恢復。已發射的子彈、放下的炸彈與被動效果繼續存在；不把整個世界一起暫停。老師原有擊退免疫不變。
- 多次衝量以剩餘位移向量相加，反向可抵銷；上限為最大單次距離的兩倍，且不超過 600 世界單位。此限制只影響密集疊加。
- 每步掃掠身體與老師實體障壁，撞到就停止這次滑動。紫霧安全圈是可穿越的傷害區，不當作硬邊界；純規則保留圓競技場掃掠供未來實體舞台使用。環形世界仍可跨接縫；老師移動粉筆牆沿用傷害型招式，並非新增實體地形牆。
- 浪花互撞在真正接觸時扣血，沿用傷害、冷卻與一次結算，不再隔空扣血。阻擋可能使擁擠處的位移變短；家長最新決定「撞到會停，比較真實」，保留身體阻擋，接受因此提高難度（`coord/inbox/done/20261026T140917Z-parent-knockback-slide-decision.md`）。此決定優先於 Grok 第一點回饋，不改成穿過怪物。
- Maker「怪物」有共用滑動秒數；自訂擊退積木可各自調整距離及 0.15～0.25 秒。缺欄位的舊作品補 0.2 秒，非法值拒絕。距離仍是有號世界單位，正推負拉。
- 練習場／預覽的擊退箭頭以目前剩餘衝量與當下障礙算終點，包含主角、老師和小頭目；不再畫舊等速猜測箭頭。若其他身體之後自行走動，終點會隨即更新。假怪也有碰撞，因此預覽位移可能縮短；結尾回位會清除剩餘衝量。

## Godot §11 對照

適用 11.1、11.2、11.6、11.7：新增參數是可序列化的數字；衝量、衰減及掃掠規則只依輸入資料、世界單位與秒，不讀 DOM、Canvas、時間或亂數。衝量狀態 `{x,y,time,limit,pending}` 都是數字，`slideHeld` 只保留本幀失控旗標；固定 1/120 秒可對應 Godot 物理更新，渲染／動畫可直接讀取位移與失控狀態，不需讓美術進入碰撞規則。測試保留固定輸入與預期距離，可在 Godot 重寫。11.3 以純規則結果 `{dx,dy,motion,hit}` 接合外層移動與碰撞傷害，未建立事件匯流排。11.4、11.5 沒有新增素材／音訊；既有 defaults.js 尚未 JSON 化，全面資料抽離與移植不在此卡範圍。
