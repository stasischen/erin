# 手動攻擊操作交接

來源：`coord/inbox/done/20261026T071532Z-parent-manual-attack-controls.md`。本次新增 Maker「數值」分頁的攻擊模式「自動／手動」，預設及舊作品均維持自動。選手動後可用正式試玩和練習場；沒有更改已確認的預設模式。

## 操作

- 左側跟隨搖桿只負責移動。
- 右側大鍵為普攻：短按在放開時攻擊，連點走連段，按住依武器既有聚氣秒數蓄力，放開出招。手動模式可邊走邊聚氣，不會站著自動累積。普通連點最短間隔 0.12 秒，最後一段另保留武器收招時間；過早放開不排隊出招。
- 按住從原按下點拖曳至少 14 遊戲畫面單位，指定方向並顯示地面箭頭；移回死區恢復自動瞄準。沒有拖曳時瞄準最近的可攻擊敵人，沒有敵人則沿面向空揮；空揮會消耗聚氣並計入連段。蓄力維持前方直線或扇形，最大 180 度；手動蓄力不附加後射，水球多發也限制於前半面。
- 普攻左上是特殊鍵，按住拖曳、放開出招。糖果大劍是穿透劍氣；棒棒糖錘是沿指定方向跳躍後前方重擊；水球是前方扇形五連發。三者獨立於普攻，冷卻均為 6 秒。跳錘不另加無敵，落地攻擊是前方 144 度。
- 普攻下方是衝刺，仍沿搖桿方向。衝刺中按普攻立即出衝刺攻擊，一次衝刺限一次；按住普攻後以第二指衝刺，也可在衝刺中放開出招。手動模式取消衝刺結束自動突刺，自動模式保留舊行為。
- 上方小鍵為泡泡炸彈。按鈕皆用既有像素圖示，無 emoji；冷卻以圓環顯示，普攻聚氣另顯示角色外圈。
- 鍵盤：WASD／方向鍵移動、J 普攻、K 特殊、空白衝刺、E 泡泡炸彈。按鈕仍提供原生鍵盤／輔助 click。
- 左搖桿、普攻、特殊各自追蹤 pointer id；錯的手指不能放開另一個輸入。取消／失去 capture 不出招；暫停、切頁、失焦、重開、換關與 resize 會清除按住狀態。

## 驗證與審查交接

Codex 只執行 `node games/survivor/tools/test.cjs`，最終 exit 0；未執行 `--layout` 或瀏覽器操作。新增 `tests/manual-attack.cjs` 涵蓋：靜止不自動出招或聚氣、按住蓄力與方向、空揮連段、取消與暫停、不同手指不互搶、衝刺按下立即出招／結束不重複、三種特殊招與冷卻、舊作品模式補齊／驗證、真正練習場使用手動模式。既有自動模式測試繼續保留。

請 Grok 對 erin-watch 提交後的完整 SHA 審查，並在 **1024×461、740×360** 實際操作：點擊連段、長按聚氣、往各方向拖曳、回到拖曳死區、左手走位＋右手聚氣、第二指衝刺、衝刺斬、三把特殊招及泡泡炸彈、取消／暫停中斷、Maker 儲存重開、練習場模式、圓鍵可達與互不遮擋。程式測試不能代替這些實際觸控檢查。自動模式是否日後改為手動預設，仍等家長決定。

## Godot §11 對照

- §11.1：`attackMode` 為可序列化字串 `auto|manual`；缺省補 `auto`、未知值拒絕。沿用現有武器聚氣數值，沒有改資料版本。預設仍在 JS 純資料中，尚未抽 JSON；特殊招目前的平衡常數在純規則 `SurvivorAttackInput.special`，未提供 Maker 調整，日後轉積木／JSON 時再抽資料。
- §11.2／11.3：`SurvivorAttackInput.step/release/special` 接收秒數、武器 id 和角度，回傳新狀態或可序列化 `attack-released`／`weapon-special` 事件，不讀 DOM 或時間。最後事件記在 `state.lastAttackInput/lastSpecialEvent`；普攻重用既有揮擊與水球碰撞、特殊交接層各自結算，尚未新增效果積木觸發類型。
- §11.4／11.5：重用像素圖示與合成音效；沒有新增外部素材或音訊原稿，既有匯出差距不變。
- §11.6：新增固定 dt、武器、輸入與預期結果測試；平台觸控／版面交 Grok 實機檢查。
- §11.7：DOM 指標座標先透過既有 `canvasPoint` 轉回遊戲方向；規則使用弧度、秒和世界距離。按鈕位置與 viewport 僅在 CSS／輸入接合層，傷害不讀版面。尚未移植 Godot。
