# 浪花水球與雙武器說明交接

對應卡片：`survivor-wave-ball-weapon-text`。來源為同名收件匣，原話已保留在 done。

## 玩法與資料

- 保留 `item-wall` id、中立身份和十張道具池位置，改名「浪花水球」，移除畫面邊緣反彈。舊 Maker 作品若仍使用「彈牆水球」名稱，讀入時換成新名稱與說明；原有取得紀錄仍使用同一 id。
- 水球命中增加擊退；棒棒糖錘在原本揮擊擊退後再追加浪花擊退。沿浪花推動路徑撞到前方另一隻可攻擊的小怪時，兩隻各受一次傷害。每次推動最多撞一隻，傷害不遞迴、不跳到其他目標。
- 初版 `neutralRules.wavePush=55`（世界距離）、`waveDamage=18`（基礎傷害）、`waveCooldown=0.6`（秒）。兩隻怪物各自記錄冷卻；冷卻內仍能擊退但不再觸發互撞。傷害沿用一般傷害入口，受到金庫、王冠、濕答答等倍率影響。
- 老師可以被額外推動，但不參與小怪互撞傷害；畫面外與登場保護中的目標仍不可攻擊。
- Maker 的「中立道具數值」可調整擊退 0–120、互撞傷害 0–100、冷卻 0.1–2 秒。舊作品缺少三個欄位時補預設；其他既有欄位仍照原本驗證。
- 49 張卡在各自 `description` 旁加入 `descriptionMelee`。兩種武器共用效果的卡保留相同文字；近戰專用文字涵蓋水花、水窪、攻速、揮擊範圍、後射、蓄電等。分裂水球保留錘子本體不分裂的註記。
- 選卡詳情與技能樹提示共用資料選擇函式；近戰欄位缺少時回用 `description`。Maker 可各自編輯遠程與近戰文字，均受原有長度與 HTML 安全驗證。
- 新圖示沿用本地程式繪製的 8×8 圓形像素水球，不含 emoji 或外部素材。看效果沿用真實引擎，兩把武器均能展示浪花互撞；移除舊展示強制把水球搬到畫面邊緣的處理。
- 版本 `20261026m`，同步遊戲、展示與 Service Worker 快取。

## 驗證與審查交接

只執行 `node games/survivor/tools/test.cjs`，不執行 `--layout`。新增 `tests/wave-ball-text.cjs`：固定位置的掃過碰撞、前後與旁側邊界、兩隻受傷、冷卻與到期、未持有道具、正式遠近攻擊、畫面外保護、致死單次結算、49 張卡文字選擇、選卡與技能樹文字、舊 Maker 遷移與安全界線、兩把武器的真實展示。既有中立測試移除反彈案例，保留後射與數量上限檢查。

請 Grok 獨立審查最後實質 SHA，執行六種 Chrome 版面檢查。通過後請 Erin 試玩：浪花推撞是否明顯、是否與雷的跳電感覺不同、錘子搭配浪花是否好玩；數值仍是初版，依試玩回饋調整。

## Godot §11 對照

- §11.1：新數值與雙版本文字皆為可序列化資料，保留穩定 id；記錄預設、單位、範圍及舊作品遷移。既有 defaults.js 尚未抽成 JSON，另卡處理。
- §11.2、11.6：掃過碰撞為固定輸入的純規則（相對座標、位移、半徑 → 第一個碰撞索引），測試不依賴時間或抽樣。持有卡判定、冷卻、傷害與效果仍由既有全域接合層負責，尚未全面純函式化。
- §11.3：沿用既有傷害／死亡結算與表現入口；不新增事件匯流排。碰撞索引可對應未來 signal 的目標 id，完整事件邊界仍待另卡。
- §11.4：保留 icons.js 8×8 圖示原稿和產生方式，匯出 PNG 留待素材移植。
- §11.5：本卡未新增音訊，沿用現有來源。
- §11.7：位移、碰撞及冷卻使用世界單位與秒，不讀 DOM 或 CSS；是否可攻擊仍沿用既有鏡頭保護規則，未改地圖行為。
