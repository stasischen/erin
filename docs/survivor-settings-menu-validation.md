## 已實作

- 開始與暫停選單共用只有像素齒輪圖示的圓形設定鍵。遊戲頂端按鈕先進入暫停選單，設定完成後回原選單，再按繼續。
- 玩家設定分操作（手動／自動、搖桿跟隨、大小、死區）、手感（打擊回饋開關／強度、畫面震動）、聲音（音樂／音效開關與音量）、顯示（低特效）四區。
- 低特效把每次純裝飾火花數量限制為 2；傷害、攻擊形狀、敵人預警與技能範圍不受影響。音量在原本音訊輸出增益上乘 0～1，保留既有溫和音量與限幅器。打擊回饋沿用既有近戰頓幀、閃白、火花及壓扁機制。
- 開始畫面的攻擊切換移到設定；橫向 compact 版面用同列的設計／開始鍵縮短高度。暫停選單的普攻欄顯示目前武器圖示、名稱，並保留已取得卡片。
- Maker 的玩家偏好集中於數值頁一個可收合的「預設設定」面板；怪物頁不再放打擊手感。作品數值、碰撞、武器設計仍維持原頁，等待外殼卡另行處理。
- 版本為 `20261026aa`，頁面、展示／練習資源查詢版本與 Service Worker 同步。

## 儲存與遷移契約

個人設定鍵為 `erin-survivor-player-settings-v1`；僅儲存 `playerDefaults` 定義的偏好欄位，不寫入血量、傷害或整份作品。作品鍵維持 `erin-survivor-maker-v1`，新增可序列化的 `playerDefaults`，只作為沒有個人偏好的玩家起點。Maker 試玩尊重個人設定；內嵌展示與練習預覽使用作品預設，不能覆寫個人偏好。

載入優先序：個人設定 → 舊 v3 設定與舊作品的偏好 → 作品／內建預設。遷移只建立新鍵，不刪除或改寫舊鍵。舊作品缺 `playerDefaults` 時，由舊攻擊模式、搖桿及 `hitJuice` 轉入。舊 v3 攻擊模式只有 `attackModeChosen: true` 才保留自動，不能借用另一份作品的明確選擇標記；其餘未明確選過自動的舊紀錄使用手動。新作品中的舊根層欄位保留作為相容資料，Maker 只編輯 `playerDefaults`。

- 搖桿半徑：20～70，畫面遊戲單位；死區：0～10，同單位；步長 1。
- 回饋強度：0～2，倍率，步長 0.1。
- 音效／音樂音量：0～1，相對原音量的倍率，步長 0.05；畫面顯示百分比。
- 其餘開關使用布林；模式使用 `manual`／`auto`。個人數值越界夾到邊界，作品預設越界拒收。
- 舊 v3 玩法數值仍可讀以保留原有體驗；玩家設定不再編輯或寫入這些數值。「恢復預設」只恢復玩家偏好，不改本局血量、敵人或武器，也不替角色回血。
- 儲存失敗時，本次遊玩仍能調整；已讀取的舊偏好不因新鍵寫入失敗而遺失。

## Codex 已執行

`node games/survivor/tools/test.cjs` 最終 exit 0，未加 `--layout`，未操作瀏覽器。版本生成使用既有 `tools/version.cjs --write` 同步。

新增 `tests/settings-menu.cjs` 的固定輸入案例：

1. 舊作品明確自動、搖桿半徑 55／不跟隨，v3 音效及震動關閉 → 遷移後保留偏好，作品原文不變，獨立鍵沒有血量或傷害。
2. 舊 v3 未標記自動＋另一份作品明確自動 → 使用手動。
3. 個人自動、半徑 60＋作品手動、半徑 35 → Maker 試玩尊重個人設定；內嵌預覽使用作品預設且不保存個人設定。
4. 暫停時血量 23、已選糖果大劍 → 普攻欄含武器名稱，恢復偏好後仍是 23 血；關閉設定再繼續可恢復遊玩。
5. 低特效下要求 20 個火花 → 只產生 2 個；其他規則不變。
6. 半徑 999、死區 -3、音量 0／4 → 分別為 70、0、0／1；損壞存檔可回預設；儲存失敗仍保留本次調整。

音訊測試另驗證音效 25%／音樂 50% 確實作用於兩個獨立輸出端，兩者 0 時輸出增益為 0。Maker 控制測試改用新預設面板並檢查儲存、重開；既有玩法測試改為不再期望玩家存檔保存傷害及血量。

## 請 Grok 親手驗證

在 **1024×461、740×360** 分別操作：

1. 首頁不用捲動就能看到完整「開始遊戲」按鈕，圓形齒輪只有像素圖示；開設定、調整、關閉，重複開啟與恢復預設時控制項都還存在。
2. 逐一切換每個設定、拖曳全部滑桿，重新整理後仍保留；實測三種武器的手動／自動、搖桿跟隨／大小／死區、打擊回饋強度與開關、畫面震動、音量及低特效。
3. 選武器、遊玩、暫停後「普攻」顯示該武器，從暫停選單齒輪進設定，返回仍停在暫停；按繼續可玩，沒有延遲出招或回血。
4. Maker 的預設設定可收合／儲存；怪物頁無個人手感面板。修改作品預設不會蓋掉已有個人設定；移除個人鍵模擬新玩家後能採用作品預設。
5. iPad／觸控拖動設定不會啟動遊戲搖桿，旋轉後沿用固定橫向與安全區；音訊仍遵守第一次使用者互動才解鎖。
