# 水流派卡片積木交接

版本 `20261026ag`。作者 Codex；交 Grok 審查 erin-watch 提交的完整 SHA，沒有作者 approve。僅遷移 water-attack、water-skill、water-dash、water-ultimate、fusion-puddle、water-drop、water-fountain、water-bubble、water-wet、water-rain；不調整平衡、卡池或其他流派設計。

## 規則與接合

十張卡的規則在 `engine/effect-blocks.js` recipes，沿用 feature id 與原 feature/power 作品格式。數值透過 build、tuning、schoolRules 的 `{ref:...}` 共用；事件輸入為等級、傷害、dt 等純數值。`event` 解讀規則，`matches` 解讀範圍、正傷害、泡泡盾、濕潤與發數倍數條件，`drop` 回傳該次普攻的大小、傷害、擊退。無作品自訂程式碼或新存檔格式。

| 卡片 | 保留的行為 |
|---|---|
| water-attack | 水花範圍嚴格小於半徑，不加目標半徑，排除本體；半徑及傷害按合併等級成長。 |
| water-skill | 水命中／泡泡爆炸留下水窪；普攻命中濕潤；水窪定時傷害、濕潤、緩速。 |
| water-dash | 沿路按原間距留水痕，與水技能共用場地及跳傷規則。 |
| water-ultimate | 第一次立即掃合法目標，其後依原海嘯間隔；多流派各自計時，空場仍顯示及重設計時。 |
| fusion-puddle | 命中留下水窪；場地原傷害、濕潤／緩速之後，再追加該目標雷傷及原閃電提示。 |
| water-drop | 每指定發數放大、增加傷害和擊退；近戰、遠程沿用共同 shot 入口，仍可與蓄電相乘。 |
| water-fountain | 等完整間隔；先推開，再重新查詢範圍內合法目標施加濕潤，保留推走後可能不再濕潤的順序。 |
| water-bubble | 衝刺結束取得一次盾；正傷害才消耗，不攔零／負值；不疊盾。 |
| water-wet | 只對濕潤目標加成；與中立倍率相乘，保留原傷害結算位置。 |
| water-rain | 等完整間隔後全場緩速／濕潤，含畫面外及入場老師；不造成畫面外傷害；持續期間按 dt 刷新，時間到不額外續跳。 |

場地保留原共用上限、先扣生命到期移除、每次更新最多一跳、範圍包含目標半徑、合併水技能／水衝刺／fusion-storm 等級取最大值。緩速的 makerSlow=0 仍是讀取 build.slowMultiplier 的既有哨兵值；沒有改動移動引擎。死亡、特效、勝敗順序與目標合法性仍由原接合層處理。為保持手感，未順便修正舊版順序或改成批次傷害。

## Maker 與舊作品

十張卡在技能卡效果選單顯示「積木堆」，可收合觸發／條件／動作、展開共用數值、預覽與儲存。水衝刺與水技能共用場地／跳傷資料。舊作品照原 schema 載入，不必重存；本次沒有重置儲存。補齊大水滴、噴泉、泡泡盾、濕答答、下雨天的預覽說明，導電水窪說明改為符合既有追加雷傷行為。資源 URL、預覽與練習場入口及 Service Worker 快取同步升版。
