# 雙刃刺客：實作與驗收

正式卡：[survivor-boss-gallery-3](../coord/tasks/specs/survivor-boss-gallery-3.md)。版本 `20261027j`；競技場半徑與 AI 距離帶沿用 hotfix，沒有新波次或擴場。Mac 工程測試不等同獨立審查或 Dot 雲端驗收。

## 正常試玩

開遊戲開始畫面的王冠圖示 → 王的試煉 → 雙刃刺客。入口有兩秒紅圈，四連斬每刀都先顯示扇形並鎖定方向；每刀間隔是 `windup + active = 0.95` 遊戲秒。每刀最後約 0.2 秒，朝 Boss 衝刺穿過或向旁閃開，可逐刀增加架勢。相同刀數不重複領取完美閃避信用。

預設兩格衝刺、1.2 秒回一格不變。預設滿條 100 在連續第四次完美閃避即破架勢，會中止未出的刀，並先提示再亮紅色弱點；抓住窗口，面朝 Boss 按住普攻聚氣後放開重擊。多次重複可把血條壓到一半以下，之後連斬改五刀、影步抽中權重提高。正在進行的四刀會先完成，不中途加刀；破架勢則立即中止。五刀資源回歸另將測試 Boss 滿條提高至 200，證明每刀皆有衝刺格，沒有修改產品的玩家或架勢預設。

影步先消失 0.35 秒，再依主角當下 `faceX/faceY` 移到背後 72 世界單位並鎖住刺擊方向。貼牆時落點限制在實心牆內，可能無法完整移到幾何上的背後；實際位置會先顯示紅扇形，最後 0.25 秒白閃後才傷害。消失期間無法被命中。苦無先用扇形預警，再從 Boss 身上射五枚並橫向滑步；完美閃避依實際彈體接觸時間。

回到試煉選單可看每隻 Boss 的最佳時間。只在成功且更快時更新；記錄活動中的真實 dt，不含入口預警與暫停，完美閃避慢動作不會縮短時間。失敗／重試不覆寫更好成績，雙子須全部擊倒才算成功。

## 數值與 Maker

Maker → 老師／怪物 → 王的試煉：可調各王血量、階段門檻、選招權重／距離／第二階段加權、每刀時機、前後半場刀數、消失／白閃／背後距離、苦無數量／速度／壽命／半徑、側滑速度。弱點積木頁可調紅色提示、護甲與暴擊、破架勢蓄力額外倍率。換位驗證要求消失＋白閃不超過整招預警，後半刀數不得少於前半。

存檔後以 Maker 的「試玩」載入作品；若先進普通關卡，暫停 → 王冠 → 確認離局 → 刺客，即使用這份作品。正常預設與 Maker 降低難度案例須分開記錄，不能把調低設定當預設通過。Dot 寫草稿須有該 PR／SHA 的明確許可，並恢復清理；不接觸原作品或正式站。

一般部位是 0.2 倍；開啟弱點是 3 倍。只有真正 `posture-break` 訊號仍有效、弱點開啟、且命中帶 `charged` 時，刺客另乘可調的 1.5 倍，合計 4.5 倍輸入傷害；不再乘老師暈眩的 3 倍。武器本來的蓄力倍率在輸入傷害中已算好。其他 Boss 沒有此額外設定，保持原規則。

每 Boss 紀錄是兩個獨立的 JSON map（id → 活動秒數）：`engine/state.js` 的 `TRIAL_RECORD_KEY = "erin-survivor-trial-best-seconds-v1"` 與 `MAKER_TRIAL_RECORD_KEY = "erin-survivor-maker-trial-best-seconds-v1"`。新增 localStorage 讀寫也只在此檔；公開候選 adapter 必須將這兩個新字面 key 一併依候選隔離，不能沿用正式站 key。`?maker=1` 或由自訂作品進入的試煉使用 Maker map。舊一王／三王作品保留既有值，只補新的刺客資料。

## 共用積木與 Godot §11

- §11.1：`sequence`、`relocate`、`projectiles`、`slide` 及弱點都是可序列化資料；穩定 id、秒、度與世界距離分開，schema 驗證／遷移／Maker roundtrip 有測試。預設仍在 defaults.js，未全面移至 JSON。
- §11.2–3：`SurvivorTrialBlocks` 純函式收固定初始狀態／dt，重用 BossAI 狀態機，輸出有序的分段與逐刀事件；大 dt 和小 dt 不漏刀。方向弧度不覆蓋扇形度數。接合層依事件移動／命中／呈現，仍保留既有 withTrialBody 與可變遊戲狀態，未建立新事件匯流排。
- §11.4：原創 16×16 字元稿與 PNG 匯出工具保留；角色、苦無、白閃、紅弱點全部經 art-manifest。紅點沿角色真實 bounds／錨點，碰撞不隨外觀改變。動畫目前是單格加程序動作；尚非完整方向 sprite sheet。
- §11.5：沿用現有 warning／perfect／posture 等合成音效及參數，未匯出 WAV／OGG。
- §11.6：純規則與真引擎回歸覆蓋四／五刀、半血中途、逐刀閃避、預設衝刺資源、背後／貼牆／白閃、苦無先射後滑、紅弱點與倍率、其他王、保存／重載／Maker 隔離及暫停計時。Godot 尚未執行；平台版面、音訊與手感仍交實際瀏覽器驗收。

- §11.7：純規則只使用世界單位／秒，不讀 DOM 或 CSS；版面與輸入換算、存檔在接合層，既有 viewport／鏡頭／世界大小的耦合保留，未全面重構。

Mac 完整命令：`node games/survivor/tools/test.cjs --layout`，另跑 `git diff --check`。完整日誌、截圖留 repo 外；獨立 session 與 Dot 對確切 PR／SHA 的證據尚須另外取得。
