# Survivor Maker：資料與驗證

## 這張卡完成的內容

- `games/survivor/data/defaults.js` 是純 JS 物件：24 張卡、三流派、欄位、技能樹前置、最高等級、玩法數值、兩種怪物、老師及七種招式、三階段、既有六波出怪表。
- `data/schema.js` 共用驗證與本機儲存。Maker 與遊戲使用同一套驗證，拒絕未知識別碼／積木、非有限數字、超限數值、前置循環和 HTML 名稱；只產生明列欄位。預警至少 0.6 秒；水球、怪物、國字、痕跡與預警數量維持上限。
- `maker/` 可改流派／卡片名稱、欄位、階段、前置卡、等級、效果組合，以及怪物數值／移動／攻擊、魔王數值／招式／階段與共用數值。全部使用繁體中文、現有顏色和 emoji；不新增美術。
- 每張卡可裝 1～3 個效果。九個通用積木為 projectile、aoe、chain、dash-trail、slow、stun、knockback、summon、ring-with-gap；可選命中、技能、衝刺、定時間隔觸發，並調整相關參數。痕跡沿衝刺路線分段留下；召喚是原地暫時自動射擊的小幫手；圈的綠色缺口不判定傷害。
- 為保留既有平衡，原本 24 種效果沿用引擎內有測試的配方實作，由資料中的 `feature` 和 `power` 接到對應能力，再讀共用數值。這些既有配方也可以換到別張卡或組合；資料裡的卡片 ID 負責持有等級／前置條件，與實際效果分開。並非把每張舊卡重新寫成通用積木；新增玩法可直接使用不帶 `feature` 的通用積木。
- 魔王招式的 `id` 負責名稱與不重複選招；`kind` 決定彈幕／衝撞／範圍／召喚／缺口圈，可獨立更換。招式參數與三階段讀取資料。若某階段只剩一招可用，允許重複出招，避免自訂條件讓老師停止攻擊。
- 怪物沿用甲本／乙本兩個可編輯種類，移動可選追逐／原地／近身後退，攻擊可選國字／有固定預警的範圍／召喚／不攻擊。既有造型不變。
- 作品鍵為 `erin-survivor-maker-v1`。按「試玩」先驗證、成功儲存後前往 `../?maker=1`，自動從 Lv1 開始；失敗時顯示原因並留在 Maker。一般入口不載入作品。自訂試玩不覆寫原本遊戲設定或最佳紀錄，Maker 紀錄獨立存放。重新整理會重新載入已儲存的作品；損壞作品會提示並退回預設。
- 關卡編輯、帳號、伺服器、個人資料、匯入／匯出均未加入；六波出怪資料已保留位置。本版編輯既有種類與卡片，不提供新增／刪除種類按鈕。
- 遊戲與 Maker 資源版本 `20261025o`；service worker 快取 `erin-games-v19`，包含兩個資料腳本與完整 Maker。

## 驗證結果

2026-10-25 在 Node.js 22 執行通過：

```sh
for file in games/survivor/tests/*.cjs; do node "$file" || exit 1; done
node --check games/survivor/game.js
node --check games/survivor/maker/maker.js
node --check games/survivor/data/defaults.js
node --check games/survivor/data/schema.js
node --check sw.js
git diff --check
```

既有九組測試只增加兩個資料腳本的載入，保留原本的斷言：平衡／技能樹與合體／特效／魔王七招及階段／攻擊範圍／鏡頭／精簡 HUD／衝刺與觸控／小兵射擊均通過。

`maker-baseline.json` 的來源為本次改檔前、HEAD `ef0f1d1a5e4ef2e4425eaee81eac32f67f621c70` 的 `game.js`，以固定亂數產生：24 張卡各測 Lv1／Lv5 共 48 組，七招各測三階段、五個時間點共 105 組。記錄傷害、射速、敵人血量、投射物位置／速度、痕跡、老師招式、落點與階段；不比較重構新增的欄位及沒有使用的內部計數。普通模式及 Maker 預設作品各自與全部 153 組原始快照逐值相等。可用 `maker-traces.cjs` 及 `maker-support.cjs` 重跑；不要用新版結果直接覆蓋基準。

`maker-data.cjs` 另驗證資料格式、循環／未知前置、數值／池上限、HTML 拒絕、壞資料／儲存失敗、本機存取來回一致；九種通用積木確實執行、改裝原本配方、卡片上限、怪物三種攻擊與停用、範圍攻擊先預警、魔王換積木／預警時間／傷害／階段、自訂最佳紀錄隔離、PWA 清單。

`maker-ui.cjs` 用 DOM 替身跑實際 Maker 腳本，驗證五個分頁能建立控制項、改名／換積木／觸發時機能存回、試玩先存檔再導向、前置循環阻擋存檔與試玩、恢復預設、儲存失敗不跳頁。

## 審查與實機待驗證

以上為工程測試，沒有代替 Grok 審查或 Erin 試玩。此工作階段無法綁定本機伺服器埠（`PermissionError: Operation not permitted`）；瀏覽器安全政策也拒絕 `file:` 本機網址，未繞過限制。因此沒有宣稱完成真瀏覽器版面、localStorage、PWA 離線或 iPad 實機測試。

Grok 請檢查新資料載入順序、格式驗證、配方轉接與一般／Maker 設定隔離，再依 erin-watch 提交後的完整 SHA 寫審查。家長可在 repo 根目錄執行 `python3 -m http.server 8000`：

1. 開 `http://localhost:8000/games/survivor/maker/`，改流派／卡名與前置、怪物攻擊和老師招式，儲存後重新整理確認保留。
2. 把一張卡換成「按衝刺時暈眩」等積木，按試玩，升級選到該卡後確認效果；暫停後按「回 Maker」返回。調整的難度和公平性由 Erin／家長試玩決定。
3. 確認一般遊戲的舊設定與最佳紀錄沒被自訂試玩覆蓋；恢復預設只還原作品。
4. 在 iPad 檢查滑桿、下拉、前置卡清單及畫面捲動；Maker 保持網頁直橫向排版，遊戲沿用既有橫向操作。
5. 在 `/erin/` 路徑的 PWA 安裝版先連線載入新版，重新啟動後斷網，確認 Maker／資料／試玩都可用。
