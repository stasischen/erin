# 王的試煉：雙子霜火、羽翼古神

原話與規格：`coord/inbox/done/20261026T170631Z-parent-boss-gallery-2.md`。版本 `20261027c`。沿用開始畫面與 Maker 練習場的「王的試煉」入口，現在可以選守門人、雙子霜火、羽翼古神。競技場、橫向全視野、實心圓牆、沒有一般波次與圖示操作均沿用第一張卡；沒有增加格擋鍵。

雙子同時在上方兩個入口出現，先有地面預警，畫面外各有箭頭。霜、火擁有各自血量、架勢、AI 狀態、選招歷史與收招時間；畫面中的兩條小血條與細架勢條各自對應一隻。近戰、主角投射物、炸彈與積木效果都能選中兩隻。一隻倒下只清除該隻的殘留危險，另一隻進入第二階段，追擊加速、解鎖天降招式，不回血；全部倒下才結算勝利。

- 霜：直線衝刺，沿途留下有短預警的冰牆地面危險區，接觸傷害與緩速、短暫存在。此版採原要求容許的「地面危險區」，不是另加實體障礙。衝刺撞圓牆會架勢暈眩並露出弱點。半血後解鎖鎖定落點的天降冰錐。
- 火：向外擴散的火環，固定安全缺口；半血後解鎖鎖定落點的隕石。
- 雙子均會使用旋轉十字光束，先有細預告線，再變成實心並旋轉。
- 古神：先升空、以落點陰影與紅圈預告，再俯衝落地；羽毛扇形從本體發射；龍捲從本體出現，先有地面圈再緩慢追蹤，五秒後消失。半血後解鎖有固定發射節拍、持續轉向安全缺口的 360° 螺旋羽毛彈幕。

落點在招式開始時鎖定；俯衝、冰錐、隕石只有落地時判定傷害。火環命中與繪圖共用半徑、厚度與缺口；十字命中與繪圖共用旋轉角度。所有飛彈從 Boss 本體出現，到牆或壽命結束時消失。沒有小怪召喚、正面護盾無敵或假弱點。

完美閃避會辨認攻擊的擁有者，只增加該王的架勢；其中一隻暈眩時仍能完美閃避另一隻。架勢滿後取消該王招式與殘留危險、沿用原有暈眩弱點／治療／蓄力加成。主角蓄力攻擊仍沿用原有前方攻擊規則。

## 積木與 Maker

`data/defaults.js` 新增穩定 Boss id `frostfire`、`winged`，仍使用版本 1 的觸發、形狀、時機、效果、回饋外殼；選招與預警／出手／收招／冷卻沿用 `SurvivorBossAI`。新形狀為 `ring` 與 `cross`；既有圓、扇形與直線繼續共用。霜火以同一份雙子定義按角色篩選招式，血量／大小／追擊速度等共用初值，戰鬥中各自保存狀態。

Maker「老師 → 王的試煉」可調兩組王的血量、大小、追擊速度、半血門檻與第二階段速度，以及每招的開始階段、AI 權重、半徑、預警／出手／收招／冷卻、傷害與移速。環形招式新增安全缺口角度欄位。權重全零仍等待，不恢復被停用的招式。只有守門人的舊 Maker 作品會保留舊設定並補上新王；新作品可完整驗證與保存。羽毛速度與龍捲追蹤速度採每招效果速度；相關招式亦顯示冰面／羽毛／龍捲壽命、生成間隔、羽毛數量、冰面剩餘速度、光束／環半寬與旋轉角度／速度。冰面冒出預警 0.6 秒、龍捲冒出預警 0.8 秒、危險區接觸傷害間隔 0.6 秒目前仍是接合層常數；未新增完整視覺編輯器。

新增純規則 `SurvivorGalleryRules`（亦可經 `Survivor.engine.gallery.encounters` 取得）：

- `stage`／`transition`：嚴格半血／夥伴倒下階段與一次性的階段事件。
- `roster`／`choose`：依霜火角色與階段篩選，交給共用 AI 抽樣，避免連續同招。
- `geometry`／`contains`：擴散環、旋轉十字與安全缺口命中。
- `volley`：從本體座標產生扇形／帶缺口的全周彈幕。
- `field`：預警、壽命、直線移動／慢速追蹤及傷害事件，不修改輸入。

`withTrialBody` 是既有單王架勢／戰鬥入口的接合層：暫時傳入正確的王，結束時保存各自狀態並恢復主要王。沒有新增第二套 AI 或架勢規則；死亡事件使用穩定角色 id。後續需要更多多王遭遇時，可另卡討論是否全面改成 actor 參數，這張卡不重構整個戰鬥引擎。
