# 波次／關卡積木交接

本卡依 `coord/inbox/done/20261026T122905Z-parent-wave-blocks.md` 製作；版本 `20261026am`。不改平衡初值。

## 使用方式

Maker → 關卡，選糖果森林或餅乾森林。每波有可收合的觸發、形狀、時機、效果、回饋積木，可改開始秒數、畫面外位置、出怪間隔、怪物種類、每批數量、提示和音效。開始時間由 0 秒遞增；第一波必須保留 0 秒。

出怪節奏項目有強弱交替／穩定、密度、兩次事件時間、事件數量／預警／進場時間，以及四種事件的種類／精英／進場方向。事件仍每場抽兩個不同種類。精英與巧克力大熊也使用五種積木；能力與本體數值沿用下方既有欄位，大熊仍每關一隻。

按「預覽」展開旁邊的即時時間表，修改數值會更新時間表；這是規則摘要，實際怪群走位按「試玩」。從餅乾森林按試玩會直接進餅乾森林，重開仍留在選定關卡；其他入口維持原本從第一關開始。作品儲存仍限本機，玩家設定獨立。

## 相容與資料邊界

- `waveBlocks: {version:1, moves:[...]}` 是新作品的權威欄位，招式使用既有五種積木外殼。穩定 id 連到關卡、怪物與事件。
- `waveStacks` 將沒有積木的舊資料轉換；`compileWaves` 純資料編譯回既有引擎接合欄位。舊 `schemaVersion:1` 和儲存 key 保留。無新函式、HTML 或程式碼輸入。
- 舊波次的時間、間隔、強弱波、事件抽選／分批進場、精英機率及大熊時間不變；原來湧潮的 `side:0` 是左邊，轉換保留左邊。
- 生怪每批 1–10 隻，大熊固定 1 隻；間隔 0.3–5 秒；所有容器、安全圈、畫面外檢查與精英上限仍由既有引擎限制。波次時間和事件時間錯誤時阻擋儲存／試玩，可直接修正數字。
- 頂層舊 `waves` 是保留相容資料；Maker 編輯各關卡波次。背景、關卡倍率及主題／事件候選池仍固定，沒有擴大關卡種類。
