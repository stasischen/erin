# 王的試煉：巨斧守門人

來源：`coord/inbox/done/20261026T164020Z-parent-boss-gallery-1.md`。本卡只加入第一隻 Boss；後兩張卡的 Boss 尚未實作。

開始畫面的 Boss 圓形像素按鈕，或招式練習場暫停選單的 Boss 按鈕，都能進入「王的試煉」。選守門人頭像直接挑戰，預設使用糖果劍與原有手動／自動攻擊設定。勝敗後回頭像選單，可再次挑戰或回原畫面。從 Maker 練習場進入時使用當前作品資料，不自動儲存；離開選單回到編輯器。

競技場是固定世界半徑的實心圓牆。主角、Boss、召喚物不能越界，投射物碰牆消失；不環繞。鏡頭沿用固定面積、橫向、全畫面跟隨，到邊緣限制鏡頭外移，牆外鋪石地與石柱裝飾。守門人從上方入口預警後開始移動；入口不在鏡頭內時沿用 Boss 邊緣箭頭。入口時不能攻擊 Boss，也不出手。不生成波次、精英、大熊或一般事件。

盾牌重擊、兩段巨斧扇形、跳躍重壓在第一階段可用。血量嚴格低於 50% 時，清掉當前招式、短暫休息，解鎖旋風斬與直線持盾衝鋒、提高追擊速度。衝鋒撞牆自己暈眩 2 秒，沿用架勢暈眩的弱點、傷害與蓄力加成。沒有正面無敵護盾、格擋鍵或假弱點。每招有地面紅色範圍與舉盾／舉斧動作；跳躍落點、衝鋒方向在預警開始鎖定。完美閃避與收招命中沿用老師架勢積木。

## 積木與 Maker

`data/defaults.js` 的 `gallery` 設定經 `SurvivorData.validate` 驗證；舊作品缺少 `gallery` 時補預設，不改原有設定。Maker「老師 → 王的試煉」可調半徑、入口秒數、撞牆暈眩、血量、速度、階段門檻，以及每招的 AI 權重、啟用階段、形狀、預警／出手／收招／冷卻與傷害。權重全設為 0 時等待，不擅自恢復已停用招式。

招式使用既有的 `blocks: {version:1, moves:[...]}` 外殼，保留觸發、形狀、時機、效果、回饋五個部分；新招式由試煉接合層執行，共用 `SurvivorBossAI.scores/choose/start/advance`。`SurvivorEffectBlocks.trial` 與 `Survivor.engine.gallery.rules` 指向同一套純規則：

- `boundary`、`rayLength`、`camera`：圓牆修正、衝鋒預告線末端與邊緣鏡頭限制。
- `phase`、`choose`：嚴格半血門檻、依階段與權重選招、不連續同招。
- `contains`：地面圓、扇形及直線命中。
- `hazard`：毒池／冰面／火圈共用持續時間、脈衝傷害與剩餘速度；回傳新狀態和 `hazard-hit` 事件，不改輸入。
- `wallStun`：邊界或未來障礙碰撞輸入轉成暈眩／弱點事件。
- `summon`：以 Boss 本體座標產生有限量召喚事件與冒出時間。

接合函式 `createTrialHazard(position, config)` 與 `summonTrialMinions(count, typeId)` 可供後續 Boss 共用。召喚物先從 Boss 身體冒出，0.6 秒後才可行動及被攻擊，有數量上限。這一隻守門人的指定五招不額外加毒池、冰面或召喚招式；Maker 顯示這些共用積木設定供後續使用。
