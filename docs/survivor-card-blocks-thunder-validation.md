# 雷流派卡片積木交接

版本：`20261026af`。本卡只遷移雷流派十張卡；保留原卡 id、Maker 的 feature/power 存檔格式、共用規則數值、卡池與平衡。作者 Codex；尚待 Grok 對 erin-watch 提交的完整 SHA 審查，不是作者自行 approve。

## 資料與接合

`engine/effect-blocks.js` 的 recipes 現在涵蓋十張雷卡；規則以 trigger、conditions、actions 描述，數值用 `{ref: 'build.x'}` 或 `{ref: 'schoolRules.x'}` 共用。數值運算支援 add、multiply、subtract、max；本次事件輸入為 level、transformed、radius、damage。引用白名單由內建 recipes 收集，不接受作品自訂程式碼或任意屬性路徑。

`event` 純函式解讀一個事件的規則，`matches` 處理圓形／線段條件，`charge` 計算蓄電門檻，`select` 依呼叫端提供的抽樣值選雷雲目標。`step` 保留靜電原有計時與事件介面，略過不同觸發的規則。`school-combat.js` 接合共用 damage/stun 動作；連鎖、電痕、避雷針沿用原有實體生命週期，改讀共用規則。卡片數值不再在雷卡分支重寫一套公式。

| 卡片 | 觸發、條件及維持的行為 |
|---|---|
| thunder-attack | 命中跳電，選範圍內最近且未命中的目標；範圍含等號，變身加範圍；傷害按合併等級成長。 |
| thunder-skill | 泡泡炸開，距離 ≤ 泡泡半徑＋目標半徑；先閃電、暈眩，再雷傷，接續原本泡泡傷害。 |
| thunder-counter | 受傷反擊，距離嚴格小於反擊範圍，不加怪物半徑；傷害按等級成長。 |
| thunder-ultimate | 沿用原多流派計時器與第一次立即生效；只抽一隻合法目標，空場仍重設計時／顯示。 |
| fusion-dash | 沿衝刺路徑按間距留下電痕；保留共用場地上限、先扣生命、到期先移除、每次更新至多一跳與連鎖。電痕半徑成長仍沿用舊版 wind-dash 等級關聯，沒有自行調整設計。 |
| thunder-charge | 每擊倒固定數目蓄電，下一次普攻強化且命中跳電；已用門檻與累積多個門檻的消耗方式不變；近戰與遠程共用。 |
| thunder-rod | 先等完整召喚間隔，最多三根；新針同次更新可攻擊，原本針先攻擊再過濾到期，不補跑多跳。 |
| thunder-step | 衝刺路段與怪物半徑＋主角半徑相碰即暈眩；包含端點與零長度路段。 |
| thunder-static | 原已遷移的定時接觸雷傷；嚴格小於接觸距離；本次確認不改行為。 |
| thunder-super | 跳電次數增加，每跳維持完整傷害；單獨取得時的行為不變。 |

目標合法性、環繞座標、視野／攻擊距離、老師入場保護、死亡獎勵、濕潤／中立道具倍率與勝敗後停止仍由原接合層處理。雷效果特效順序不變，沒有把所有傷害預先批次結算。

## Maker 與舊作品

技能卡效果選擇中，十張卡顯示「積木堆」，不再標「原本組合」。積木堆可收合，內含觸發／條件／動作；另可展開共用數值，用滑桿或加減按鈕修改。收合狀態在這次開啟設計室期間保留，切卡、重新顯示與預覽不會重設。既有整卡／單效果預覽均沿用實際引擎，補齊蓄電、避雷針、雷步、靜電與超導體的預覽說明。

這次不改作品 schema，不強制重存或重置舊作品；原 feature id 會對應到積木規則。數值修改與儲存仍通過原有 schema 驗證，重開／試玩使用同一份作品。這不是任意節點編輯器；新增觸發類型或改造實體生命週期仍需接合層支援。

## 驗證與審查者操作

Codex 執行指令僅 `node games/survivor/tools/test.cjs`，未加 `--layout`。

- `tests/effect-blocks-thunder-legacy.json` 凍結開工前 `df21ff868a4c2f41de92f3186fab757f6682b425` 的相關函式，不由新版規則反推預期。
- `effect-blocks-thunder.cjs` 比較 142 組固定情境的完整戰鬥狀態與有序傷害／閃電：零／一般／封頂等級、超導體／變身、排除目標、長短 dt、擊倒、自訂數值、環繞、入場老師、電痕與計時。另對照蓄電門檻與已消耗門檻，十張真引擎預覽與純函式輸入不變。
- 原 `effect-blocks.cjs` 繼續比較更早的靜電／王冠獨立舊版，避免兩份新規則互相作證。
- `maker-ui.cjs` 載入真實積木登錄表，逐張操作十張雷卡的收合、單效果預覽、共用傷害加一、儲存重載。測試 DOM 替身補上預覽所需的 querySelector。
- `levelup-reroll.cjs` 的既有隨機測試偶爾抽到幸運草；取得幸運草原本就送一次重抽。只修正該測試的預期，保留獎勵，遊戲重抽規則未改。
- 資源 URL、preview/practice 載入與 Service Worker 快取均同步版本。

請 Grok 在 **1024×461、740×360** 實際上手：進 Maker 技能卡，逐張選十張雷卡，收合／展開、按加減與滑桿、看單積木預覽、儲存後重開；修改跳電範圍、雷傷、避雷針間隔再試玩確認效果。親手玩到這些卡，對照連鎖次數、泡泡暈眩、受傷反擊、蓄電、沿路電痕和雷雲；確認三把武器與舊作品手感。Codex 自動測試不取代這些操作；版面與觸控驗收尚待審查者。
