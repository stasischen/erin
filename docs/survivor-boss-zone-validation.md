# 老師戰安全圈驗證

依據：`coord/inbox/done/20261025T162916Z-parent-boss-zone.md`。版本：`20261026d`。作者 Codex；等待 Grok 獨立審查及 Erin 試玩。衝刺改進已在依賴卡完成，本卡接續加入戰場安全圈。

## 試玩行為與初值

- 老師出場時，以當時戰場的鏡頭中心（主角當時所在位置）固定安全圈中心；環狀世界沒有唯一中心，不把主角移到遠處的地圖座標中心。圈不跟著主角移動，幾何、回圈指示、生成與扣血均共用 wrapped 最短距離。
- 大圈初始直徑為出場時螢幕長邊的 3 倍。第一階段及後續兩次轉階段，各預告一次縮圈；每次提前 4 秒顯示金色虛線及倒數，再以每秒 40 距離收圈。預設直徑依序為 2.5、2、1.5 個螢幕寬。快速打入下一階段仍依序演出完整預告與收圈。
- 圈外地面是半透明紫霧；主角在邊界前 100 距離及圈外會看到邊緣箭頭，箭頭朝安全區。圈外顯示回圈提醒，移速剩 80%，每秒扣 2 血。傷害依遊戲時間逐步扣除，可慢慢扣到遊戲結束，沒有瞬殺判定；衝刺／受傷無敵與技能展示免傷仍有效。紫霧不反覆觸發音效與反擊技能。
- 老師召喚的小怪在安全圈內生成；一般波次仍從畫面外生成。先前已在圈外的小怪沿原有追蹤邏輯走回主角。沒有新增敵人種類或波次。
- Maker 的「魔王」頁可開關縮圈、設定次數（0～3）、速度（10～160）與每秒傷害（0～4）。減少次數時，在最初對應的階段收圈，最後同樣到 1.5 螢幕寬；0 次保留大安全圈，關閉則完全沒有紫霧。舊作品自動補預設設定。
- 設定、升級及其他暫停會凍結縮圈與紫霧；重新開始、換關或結束會清掉圈。視窗放大時同比放大圈，保留最小躲避空間；變小時不額外收圈。技能展示的獨立場景停用戰場縮圈，完整 Maker 試玩啟用作品設定。
- 已更新 version.json、兩個遊戲入口與展示 URL 的資源版本及 Service Worker 快取。

以上均為依收件匣實作的可試玩初值，未視為 Erin 已確認平衡。
