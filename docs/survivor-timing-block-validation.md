# 共用時機積木交接

來源：`coord/inbox/done/20261026T092640Z-parent-timing-block.md`（統一拼圖第 3 步）。

## 資料與行為

- 主角武器使用 `weapon.timing`，敵人使用 `phaseAttack.timing`；格式皆為 `{windup, active, recovery, cooldown}`，單位秒。主角普攻試玩初值為 `0.1 / 0.05 / 0.12 / 0`，可在 Maker 調整。
- 純規則位於 `engine/timing.js`：`start`、`advance`、`cancelRecovery`、`segments`。狀態與事件只有資料；`entered` 只在換階段為 true，接合層僅在進入生效階段出招一次。每次更新最多跨一個有時間的階段，維持舊敵人的掉幀處理；主角略過零秒階段。
- 敵人舊版平面時間欄位會自動轉成時機積木；保留平面欄位供舊顯示／資料讀取。新作品同時有兩種格式時以 `timing` 為準，驗證後同步平面欄位。無積木的舊執行資料仍可直接使用；存檔 schemaVersion 維持 1，以缺省欄位遷移，不丟棄作品。保留敵人較嚴格的預警下限與原攻擊節奏。
- Maker 武器與怪物頁共用四段時間軸與秒數編輯，改動即更新。敵人的形狀、傷害與時間分開；練習畫面讀同一份時機，敵人加速練習時同步起手秒數。
- 手動普攻放開後起手，進入生效時才發射／揮擊，保留放開時的方向與蓄力結果。生效為一次性命中／發射後的階段時間，不額外延長近戰碰撞或取消已射出的子彈。忙碌時不排隊或重複出招。
- 成功衝刺可取消收招（包含連段最後一擊的額外收招），但保留冷卻；起手與生效不會被取消。自動普攻、既有特殊招式與特殊招冷卻維持原規則。暫停凍結待出招，重開清除待出招。
- 資源與 Service Worker 版本：`20261026ac`。
