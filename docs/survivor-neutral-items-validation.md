# 十種中立道具：工程驗證與試玩交接

來源：`coord/inbox/done/20261025T184823Z-parent-neutral-items.md`。版本 `20261026h`；提交、push、PR 由 erin-watch 處理，未核准上線。水球沿用上一卡的主流派配色／合體漸層，中立道具不增加流派張數、不改變起始精靈或變身條件。

## 本次行為

- 新增彈牆水球、爆爆糖、小鳥跟班、小金庫、分裂水球、磁鐵、王冠、幸運草、後射、回力餅乾，全部無流派。普通／稀有品質沿用既有卡片抽選；Maker 可調品質、名稱、圖示、效果與數值。
- 每場從十種抽五種進固定中立池，重抽不更換池，兩關共用；五種為可調工程初值，Maker 可設 1–9 種，保留「只提供一部分」。每種都可能抽入，不要求先選特定流派。
- 初版每種最多拿一次；Maker 仍可編輯最高等級，固定機制不隨重複等級放大（同一能力依是否持有判定）。所有卡有獨立像素圖示、選卡／已持有／Maker 的共用引擎展示；技能樹列出當局中立池。
- 彈牆在**目前可見畫面邊緣**反彈一次，角落只耗一次，保留射程與命中記錄；不更改環形世界邊界。
- 爆爆糖每次一般敵人死亡抽一次 10%，掉落可見糖果炸彈，0.6 秒後半徑 70、傷害 45；同時最多 12 顆，連鎖掉落下次更新才倒數，不會同步無限遞迴。死亡既有旗標防重複結算。
- 小鳥半徑 65 繞行，每 0.8 秒啄距離 90 內最近的可攻擊目標，基礎傷害 20，有鳥圖示及啄擊軌跡。
- 小金庫持有後每撿十顆**經驗球物件**傷害 +1%，最多 +30%，不以球內 XP 或金幣計數。球數跨關保留，有金庫圖示與加成百分比。
- 分裂水球直接打倒一般敵人時產生兩顆 50% 傷害碎片；穿透母球最多觸發一次，碎片不再分裂。承接配色、射程、命中記錄，沿用水球總數上限。
- 磁鐵拾取半徑 2.5 倍，與既有磁鐵／輕飄飄相乘，有淡色範圍圈。
- 王冠所有經由共用傷害入口的攻擊傷害 +30%、最大血量 -1（至少 1）；取得時將現有血量限制到新上限。卡面寫明詛咒，角色上方顯示王冠，展示含血量上限。
- 幸運草取得時增加一次重抽，稀有權重乘 1.6，沒有提高傳說額外出現機率；展示顯示重抽數與權重倍率。
- 後射每輪普攻向主射方向反向多一發，沿用當輪配色、傷害與彈牆設定。
- 回力餅乾持有後每擊倒 20 隻一般敵人回 1 血，不超過上限；顯示進度與綠色回血字樣。沒有持有時不預存擊倒／球數。

以上新增數值除需求已明定者外為工程初值，尚待 Erin 試玩確認；沒有新增角色、武器或解鎖系統。

## 資料與 Godot §11 對照

- §11.1：內容、品質、穩定 `item-*` id 與 `neutralRules` 在 `data/defaults.js`，均可 JSON 序列化；`data/schema.js` 驗證範圍、整數與中立身份，舊作品缺少新區塊／卡片依 id 補入，保留舊名稱及數值。沒有在本卡全面抽成獨立 JSON。
- `neutralRules` 單位：`itemsPerRun` 張；`bombChance` 機率；`bombDelay`、`birdSeconds` 秒；`bombRadius`、`birdRadius`、`birdReach` 世界距離；`bombDamage`、`birdDamage` 傷害；`bankEvery` 球數；`bankStep`、`bankCap`、`crownDamage` 傷害加成比例；`splitDamage`、`magnetMultiplier`、`luckyRareMultiplier` 倍率；`splitAngle` 弧度；`crownHealth` 血量；`cookieKills` 隻數。預設在 defaults，允許範圍在 `NEUTRAL_BOUNDS`，Maker 以中文標示。
- §11.2／11.3：`SurvivorNeutral.reward`、`damage`、`bounce` 是無 DOM／音訊／全域讀寫的純規則；時間、亂數、位置與能力由外層傳入。獎勵輸出新計數及 `heal`、`bomb-dropped`、`bank-grown`、`item-acquired` 序列化事件，外層消費事件產生物件、音效和展示。沒有新增全域事件匯流排；物件池、目標選擇及飛行仍接既有有狀態引擎。
- §11.4／11.5：十張卡的獨立 8×8 程式圖共用既有 16×16 繪製介面，保留 icons.js 原始格點，尚未匯出 PNG；沒有新增音訊素材，沿用現有本地音效。
- §11.6／11.7：新增固定輸入→輸出測試；規則以遊戲距離及秒運作，反彈由外層傳入鏡頭矩形，純規則不讀 CSS／DOM。尚未整體分離世界與螢幕設定，沒有改動移植時程。
