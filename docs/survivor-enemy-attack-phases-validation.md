# 敵人分階段攻擊交接

來源：[家長需求](../coord/inbox/done/20261026T034719Z-parent-enemy-attack-phases.md)。版本 `20261026o`。只實作共用階段、三種小怪和身體碰撞設定；甜甜圈、跳跳糖既有行為保留，沒有新增 Boss／精英霸體或連招。

## 玩法與工程初值

- 布丁：進入 125 距離後固定原點與朝向，抬高身體並亮圈，預警 0.9 秒；半徑 95、110 度扇形生效 0.25 秒，傷害 12，每次攻擊最多命中一次。
- 蘑菇：340 距離觸發，紅線預警 0.9 秒後向鎖定方向射一發；半徑 10、速度 140、距離最多 280，傷害 6，生效 2 秒。
- 棉花糖仙子：保留護盾預警與施放；護盾動作與攻擊動作依序進行。攻擊起手 0.9 秒後射出 8 發慢速圓形糖果，朝玩家方向留 70 度缺口；其餘子彈數值同蘑菇。
- 三種攻擊收招停頓 0.65 秒、冷卻 3 秒。收招顯示「反擊機會！」。起手、生效、收招時停止自主移動；既有玩家擊退照常有效，攻擊原點不跟著移動。
- 一般小怪（含精英）身體傷害預設乘 0.25，小熊軟糖為 3.75、蒲公英為 3。Maker 可逐隻調原始碰撞傷害，也可調共用倍率；「碰撞只會推開，不會受傷」開啟後推開重疊小怪並停用身體傷害。獨立攻擊仍可造成傷害。老師與巧克力大熊沿用原有身體碰撞規則。

這些是可試玩的初值，不視為 Erin 已確認平衡。Maker「敵人」頁可編輯每隻的啟用、形狀、尺寸、起手／生效／收招／冷卻秒數、傷害、觸發距離、子彈速度／數量／缺口。關閉分階段攻擊後回到下方舊攻擊設定；其餘五種小怪也可開啟共用系統。

## 規則與資料契約

`data/defaults.js` 的 `enemies[].phaseAttack` 為純資料，單位是世界距離、每秒距離、秒、角度與傷害；`data/schema.js` 的 `PHASE_BOUNDS/PHASE_SHAPES` 為安全範圍及 Maker 控制來源。`enabled/radial` 是布林。`bodyContact` 放共用身體碰撞設定。缺少新欄位的舊作品補預設，其餘既有欄位保留；顯式關閉可儲存。

直線（矩形，radius 是半寬）、扇形、圓形、圓環使用相同鎖定原點、方向、尺寸繪製預警與生效範圍。判定主角**中心**是否落入形狀，不額外擴大命中；邊界包含在內。圓環內半徑必須小於外半徑。扇形角度是完整張角，角度單位為度。

子彈型態預警固定飛行路線的掃掠範圍，含子彈及主角碰撞半徑；中央細線表示方向，寬的淡紅線表示危險帶。路線長度為 `min(length, speed × active)`，不跟隨玩家。實際子彈用既有圓形碰撞，最長壽命為 `min(active, length / speed)`，生效結束前回收；離散更新不超過預警的最遠距離。`radial` 開啟時，子彈平均分布在缺口以外的弧線，缺口朝起手鎖定方向；count 為 1 時只射一發。

純函式 `SurvivorPacing.advanceAttack` 接收狀態、設定、dt，回傳新階段；每次最多切換一階段，避免大 dt 跳過整段提示。`inShape/attackAngles` 不讀 DOM、Canvas、時間或亂數。平台接合層 `updatePhasedAttack` 才播放聲音、產生子彈與走既有傷害入口。暈眩凍結階段；出畫面取消未完成攻擊，回來重新起手；死亡後不繼續近戰判定，已射出的子彈在原生效壽命內保留。暫停不更新，重新開始／換關清空敵人與子彈。

## 驗證與交接

執行 `node games/survivor/tools/test.cjs`，沒有加 `--layout`。新增固定輸入案例涵蓋四階段、鎖定方向、形狀內外與邊界、單次命中、蘑菇直線命中與壽命、仙子護盾和缺口、暈眩／暫停／出畫面／死亡／重開／世界接縫、兩種沙包傷害、碰撞開關、舊作品遷移、錯誤數值拒絕、儲存載入與繪圖形狀。Maker UI 測試實際操作新開關、倍率與階段參數並儲存重開。舊碰撞測試按新倍率更新；舊蘑菇射擊測試關閉新攻擊，以保留相容路徑覆蓋。沒有重錄既有卡片快照。

請 Grok 對 erin-watch 提交的 SHA 獨立審查及跑 `--layout`。Erin 試玩重點：紅色預警是否容易看清、布丁是否有足夠時間躲開、仙子的缺口是否好鑽、碰撞傷害是否合適。
